# 📝 会议纪要归档说明

> 本文件夹用于存放与业务方、研发、测试等各方沟通的会议纪要，便于后期回溯需求背景、确认过程和决策依据。

---

## 📁 文件命名规范

统一使用以下格式命名，方便按日期和主题检索：

```
YYYY-MM-DD-会议主题.md
```

**示例**：

| 文件名 | 说明 |
|---|---|
| `2026-08-08-发货单功能确认.md` | 2026年8月8日关于发货单功能的沟通会议 |
| `2026-08-10-采购单货权调整评审.md` | 2026年8月10日货权调整需求评审会 |
| `2026-08-15-业务方需求对齐.md` | 2026年8月15日与业务方的需求对齐会 |

---

## 📋 会议纪要模板（推荐）

每次新建会议纪要时，可参考以下结构复制使用：

```markdown
# 【会议主题】

| 字段 | 内容 |
|---|---|
| 会议日期 | 2026-XX-XX |
| 会议时间 | XX:XX - XX:XX |
| 会议地点 / 形式 | 线上 / 线下 / 腾讯会议 |
| 参会人员 | 产品：XXX；业务：XXX；研发：XXX；测试：XXX |
| 会议主持人 | XXX |
| 记录人 | XXX |

## 一、会议背景
（简要说明本次会议的目的、为什么要开这个会）

## 二、讨论议题
1. 议题一：XXX
2. 议题二：XXX

## 三、讨论内容与过程

### 3.1 议题一：XXX
- 业务方提出：XXX
- 研发反馈：XXX
- 讨论结果：XXX

### 3.2 议题二：XXX
...

## 四、会议结论 / 决策点
| # | 决策内容 | 责任人 | 截止日期 | 状态 |
|---|---|---|---|---|
| 1 | XXX | XXX | 2026-XX-XX | 待跟进 |
| 2 | XXX | XXX | 2026-XX-XX | 待跟进 |

## 五、待确认 / 待跟进问题
- [ ] 问题一：XXX（需要和谁确认）
- [ ] 问题二：XXX

## 六、附件 / 参考资料
- 相关 PRD 文档链接
- 原型页面链接
- 其他资料
```

---

## 🗂 使用建议

1. **及时归档**：会议结束后 24 小时内整理好纪要放入本目录。
2. **关联 PRD**：如果某次会议内容影响了产品方案，请在对应 PRD 文档中引用该会议纪要文件名。
3. **状态跟踪**：决策点和待办事项建议使用 Markdown 复选框 `- [ ]` / `- [x]` 标记完成情况。
4. **按主题查找**：后期可通过文件名的主题关键词快速定位相关会议（如搜索"货权调整"可找到所有相关会议）。

```
复制模板 → 重命名为 YYYY-MM-DD-主题.md → 填写内容
```
