## 一、会议背景

发货单页面原型已完成 v1.5.1 版本，本次会议与业务方确认发货单的核心字段、状态流转规则、以及与采购计划/发货计划的联动关系，为后续撰写正式 PRD 做准备。

## 二、讨论议题

1. 发货单的状态流转（草稿 → 待审核 → 已出库 → 已签收 → 已完成）
2. 一张发货单对应多个 SKU、多个发货计划的拆分规则
3. 费用分摊逻辑（运费、报关费等）
4. 与 WMS 系统对接的出库节点

## 三、讨论内容与过程

### 3.1 发货单状态流转
- 业务方提出：新增"作废"状态，已出库前的发货单允许作废
- 研发反馈：作废后需要关联反向的库存回滚逻辑
- 讨论结果：状态增加"作废"，作废后库存自动退回在途

### 3.2 SKU 与发货计划关联
- 业务方：一个 SKU 只能对应一个发货计划行，不能拆分
- 产品：确认原型中表格每行显示"对应发货计划号"字段
