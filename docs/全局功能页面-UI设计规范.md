# 全局功能页面 UI 设计规范

> **版本**：V1.0  
> **更新日期**：2026-11-02  
> **适用对象**：产品、UI、前端开发、测试  
> **参考页面**：采购计划页面  
> **适用范围**：带有“顶部导航 + 左侧导航 + 查询区 + 操作区 + 状态栏 + 一级/二级列表 + 底部汇总”的中后台功能页面。

## 1. 规范目标与执行原则

本规范用于统一全局功能页面的视觉和布局，前端开发时不得仅凭截图估算样式。业务页面可以调整字段、列宽和状态枚举，但不得自行改变全局字体、基础控件高度、模块间距、卡片结构和列表层级。

执行优先级：

1. 全局设计变量与共享组件；
2. 本规范中的页面结构规范；
3. 业务页面的字段、列宽和状态差异。

统一要求：

- 尺寸、间距、字号均以 `px` 为单位；颜色使用十六进制色值。
- 页面采用桌面端中后台布局，内容区随视口宽度自适应。
- 只保留必要的视觉层级，不使用多余阴影、彩色分区或重复标题。
- 查询卡片、操作行、列表卡片必须左右严格对齐。
- 表格只保留横向分隔线，不使用竖向表格线。

---

## 2. 页面设计基准与适配

| 项目 | 规范 |
|---|---|
| 设计基准 | 以 1440px 宽桌面视口作为主要设计与验收基准 |
| 页面结构 | 顶部导航固定 48px；下方为左侧导航 + 自适应内容区 |
| 内容区宽度 | `可用视口宽度 - 左侧导航宽度`，不得设置固定内容宽度 |
| 内容区背景 | `#F5F7FA` |
| 卡片背景 | `#FFFFFF` |
| 卡片边框 | `1px solid #E5E9EF` |
| 卡片圆角 | `8px` |
| 卡片阴影 | 默认无阴影 |
| 窄屏适配 | 查询项自动换行；表格列放不下时由表格容器横向滚动 |
| 容器收缩 | Grid/Flex 子容器必须允许收缩，避免内容撑破页面 |

页面不得因为表格或查询项过宽而出现整页横向滚动；横向滚动应限制在对应组件内部。

## 3. 全局字体、颜色与间距

### 3.1 字体族

全局统一使用系统字体，不额外引入商业字体：

```css
font-family: Arial, "PingFang SC", "Microsoft YaHei", sans-serif;
```

- 中文优先使用苹方，Windows 回退到微软雅黑。
- 数字和英文可使用 Arial。
- 同一信息层级不得混用不同字体族。

### 3.2 字号与字重

| 使用场景 | 字号 | 字重 | 建议行高 | 颜色 |
|---|---:|---:|---:|---|
| 全局正文、导航、控件、一级列表 | 14px | 400 | 20px | `#606266` |
| 一级导航、状态 Tab、重点菜单 | 14px | 500–600 | 20px | 按对应状态 |
| 一级列表表头 | 14px | 500 | 20px | `#606266` |
| 二级列表表头与正文 | 12px | 400–500 | 18px | `#606266` |
| 查询占位文字、辅助说明、状态标签 | 12px | 400 | 18px | 按对应状态 |
| 底部汇总文字 | 13px | 400 | 20px | `#606266` |
| 底部汇总数值 | 13px | 600 | 20px | `#303133` |
| 弹窗或业务分区标题 | 16px | 600 | 24px | `#303133` |

字重只允许使用 `400`、`500`、`600`，不得使用过大字重制造视觉压迫。

### 3.3 全局颜色

| 类型 | 色值 | 用途 |
|---|---|---|
| 主要文字 | `#303133` | 标题、重点数值、选中前的重要信息 |
| 常规文字 | `#606266` | 正文、表头、控件已选值 |
| 次要文字 | `#909399` | 占位文字、辅助说明、未选中数量 |
| 禁用文字 | `#C0C4CC` | 禁用输入与不可用操作 |
| 品牌/链接蓝 | `#1677FF` | 单号链接、焦点、常规品牌强调 |
| 操作/选中蓝 | `#409EFF` | 主操作按钮、选中状态 Tab |
| 主按钮 Hover | `#4096FF` | 品牌主按钮悬浮；实色操作按钮按组件体系处理 |
| 页面底色 | `#F5F7FA` | 内容画布 |
| 一级表头底色 | `#F5F7FA` | 一级列表表头 |
| 二级表头底色 | `#F3F6FA` | 二级列表表头 |
| 行 Hover 底色 | `#F5FAFF` | 表格行悬浮 |
| 常规边框 | `#DCDFE6` | 输入框、普通按钮 |
| 卡片/模块边框 | `#E5E9EF` | 页面卡片 |
| 一级表格分隔线 | `#E4E9F2` | 一级表头及数据行 |
| 二级表格分隔线 | `#E6EBF2` | 二级表头及数据行 |
| 成功 | `#67C23A` / `#19A974` | 成功操作或完成状态 |
| 警告 | `#E6A23C` | 待处理、部分完成、警告 |
| 危险 | `#F56C6C` | 驳回、作废、删除、错误 |

### 3.4 间距体系

页面结构以 `10px` 为主间距，组件内部使用 `4px / 8px / 12px / 16px`，不得随意出现无规律的间距。

| 场景 | 间距 |
|---|---:|
| 内容区四周 | 10px |
| 查询卡片 → 操作行 | 10px |
| 操作行 → 列表卡片 | 10px |
| 查询项之间 | 12px |
| 查询按钮组内部 | 8px |
| 操作区按钮之间 | 10px |
| 图标与文字 | 8px；紧凑场景可用 4–6px |
| 卡片常规内边距 | 16px |
| 表格单元格左右内边距 | 一级 12px；二级 8px |

## 6. 页面内容容器与模块间距

标准纵向结构：

> 查询卡片 → 10px 灰色间隔 → 操作按钮行 → 10px 灰色间隔 → 列表卡片

| 区域 | 布局与尺寸 |
|---|---|
| 内容容器 | Padding 10px；背景 `#F5F7FA` |
| 查询卡片 | 白底、1px 浅灰边框、8px 圆角；有效内边距为 `16px 18px` |
| 操作按钮行 | 高度 32px；透明背景；无边框、无卡片、无阴影 |
| 列表卡片 | 白底、1px `#E5E9EF` 边框、8px 圆角 |
| 状态栏与表格 | 必须属于同一列表卡片，不得分别再套一层卡片 |
| 底部汇总 | 与列表卡片连续，上边界使用横向分隔线 |

硬性要求：

- 查询卡片、操作行和列表卡片的左、右坐标必须完全一致。
- 不得通过页面级左右 Margin/Padding 叠加，导致按钮行比卡片突出。
- 查询卡片上下内边距必须相等，均为 16px。
- 没有可切换业务页签时，不在内容区重复展示页面名称。

## 7. 查询区

### 7.1 布局

| 元素 | 规范 |
|---|---|
| 查询区布局 | Flex 自动换行，按 DOM 顺序从左到右紧凑排列 |
| 查询项间距 | 水平、垂直均为 12px |
| 默认展示 | 最多两行；实际溢出第三行时才显示“展开” |
| 普通查询项 | 基础宽度 200px，可按容器适当收缩 |
| 组合查询项 | 下拉类型 + 输入框；内部间距 6–8px |
| 单号组合项示例 | 总基础宽度 350px；类型下拉 132px，输入框自适应 |
| 日期组合项示例 | 基础宽度 430px；时间类型 + 日期范围 |
| 查询按钮组 | 展开/收起 → 查询 → 重置；整组跟随最后一个查询项 |
| 按钮组内部间距 | 8px |

不得使用空白占位、固定空列或强制右对齐制造布局；空间不足时按钮组整体换行，不能拆开。

### 7.2 输入框、下拉框和占位文字

| 属性 | 规范 |
|---|---|
| 控件高度 | 32px |
| 控件背景 | `#FFFFFF` |
| 控件边框 | `1px solid #DCDFE6` |
| 控件圆角 | 4px |
| 普通输入框左右内边距 | 11px |
| 下拉框 | 左内边距 11px；右侧为箭头/清空区域预留 30px |
| 输入值文字 | 14px / 400，`#606266`；紧凑组合框可使用 13px |
| 占位文字 | **12px / 400，`#909399`** |
| 多选占位格式 | `请选择XXX`，不额外写“可多选” |
| 输入占位格式 | `请输入XXX`；支持多值时补充分隔方式 |
| 控件 Focus | 边框 `#1677FF`，可配 `0 0 0 2px rgba(22,119,255,.10)` |
| 控件 Disabled | 文字 `#C0C4CC`，浅灰边框，禁止操作 |

查询区不显示独立 Label，字段名称通过 Placeholder 表达。多选值较多时使用折叠标签，不得撑高或撑宽控件。

### 7.3 查询按钮

| 类型 | 高度 | 左右内边距 | 字号/字重 | 样式 |
|---|---:|---:|---|---|
| 查询 | 32px | 18px | 14px / 400 | 蓝底白字，4px 圆角 |
| 重置 | 32px | 18px | 14px / 400 | 白底、浅灰边框、常规文字 |
| 展开/收起 | 32px | 8px | 12px / 400 | 透明底、灰色文字；图标与文字间距 4px |

## 8. 操作按钮区

| 元素 | 规范 |
|---|---|
| 区域高度 | 32px |
| 区域背景 | 透明，直接使用页面灰色画布 |
| 按钮高度 | 32px |
| 按钮左右内边距 | 16px |
| 按钮文字 | 14px / 400 |
| 按钮圆角 | 7px |
| 相邻按钮间距 | 10px |
| 主按钮 | `#409EFF` 背景、白色文字 |
| 次按钮 | 白底、`#DCDFE6` 边框、`#606266` 文字 |
| 危险按钮 | `#F56C6C` 背景、白色文字 |
| 禁用按钮 | 文字 `#C0C4CC`、边框 `#EBEEF5`、白底 |

按钮主次规则：

- 新建等核心主流程操作使用实色主按钮。
- 导出、更多等辅助操作使用白色次按钮。
- 危险操作使用红色，不得为了“醒目”把普通操作也做成红色。
- 同一行实色按钮原则上不超过 3 个。
- 依赖单据状态的批量按钮，应随当前状态 Tab 联动显隐，不得点击后才提示不可操作。

## 9. 状态栏与状态 Tabs

状态栏指列表卡片顶部用于切换单据状态的区域，不包括底部汇总。

| 元素 | 规范 |
|---|---|
| 状态栏总高度 | 50px |
| 状态 Tab 内容高度 | 48px |
| 状态栏左右内边距 | 16px |
| 状态栏背景 | `#FFFFFF` |
| Tab 之间间距 | 25px |
| Tab 文字 | **14px / 500** |
| 未选中文字 | `#303133` |
| 选中文字 | `#409EFF` |
| 选中指示线 | 底部 2px，`#409EFF` |
| Hover 文字 | `#1677FF` 或统一操作蓝 |
| 数量气泡最小宽度 | 22px |
| 数量气泡高度 | 18px |
| 数量气泡左右内边距 | 6px |
| 状态文字与数量间距 | 6px |
| 数量文字 | 12px / 400 |
| 默认气泡 | 背景 `#F2F4F7`，文字 `#909399` |
| 选中气泡 | 背景 `#ECF5FF`，文字 `#409EFF` |
| 气泡圆角 | 10px |

要求：

- 状态栏与下方表格是同一卡片的连续区域。
- 状态栏底部不额外添加重复分隔线，由表头边界承接。
- 状态过多导致空间不足时，状态栏内部横向滚动，不得压缩文字或换行。
- 切换状态时保持栏高、间距和其他按钮位置不变。

采购计划页示例列宽：

| 列 | 宽度规则 |

| 复选框列 | 48px |
| 展开列 | 36px |

- 行内编辑图标按钮点击区域 22px × 22px，图标约 15px × 15px。
- 长文本单行省略，Hover 时通过 Tooltip 查看完整内容。
- 同列保持统一对齐；文本默认左对齐，数值可按业务需要右对齐。
- 固定列只允许使用轻量阴影表示滚动边界，不增加实体竖线。

## 11. 二级列表

二级列表用于表达一级单据下的 SKU、明细或子件，不得简单复制一级列表样式，应通过更紧凑的行高、更小的字号和独立底色体现层级。

### 11.1 一级与二级列表对照

| 属性 | 一级列表 | 二级列表 |
|---|---|---|
| 表头高度 | 47px | **40px** |
| 表头字号/字重 | **14px / 500** | **12px / 500** |
| 表头文字色 | `#606266` | `#606266` |
| 表头背景 | `#F5F7FA` | `#F3F6FA` |
| 数据行高度 | 56px | **40px** |
| 正文字号/字重 | 14px / 400 | **12px / 400** |
| 单元格内边距 | `6px 12px` | `7px 8px` |
| 行分隔线 | `#E4E9F2` | `#E6EBF2` |
| 数据行背景 | `#FFFFFF` | `#FFFFFF` |
| 信息密度 | 常规 | 紧凑 |

### 11.2 展开区域

| 元素 | 规范 |
|---|---|
| 展开行外层背景 | `#F7F9FC` |
| 展开内容区内边距 | 上/下 12px，右 18px，左 3px（相对展开单元格） |
| 二级表格背景 | `#FFFFFF` |
| 二级表头背景 | `#F3F6FA` |
| 二级单元格 | 默认左对齐，文本不换行 |
| 二级复选框列 | 44px；复选框 16px × 16px |
| 二级空数据行 | 高度 56px，居中，`#909399` |
| 二级汇总行 | 高度 44px，背景 `#F5F7FA`，文字 `#303133` / 600 |

层级与交互要求：

- 展开/收起只改变当前一级行的明细区域，不改变其他一级行高度。
- 二级列表与父级单据关系必须清晰，不得出现无法判断归属的浮空表格。
- 父级固定列与二级固定列分别计算，不得互相覆盖。
- 二级列表出现横向滚动时，关键识别列（复选框、SKU、品名、团队等）可固定在左侧。
- 固定列边缘使用轻量阴影，例如 `6px 0 8px rgba(31,35,41,.07)`，不得添加粗竖线。
- 二级标签（组合、加急、移除等）使用 11px 字号，紧跟对应字段，间距 6px。
- 展开辅助列只显示箭头，不出现省略号、点号或其他尾随字符。

汇总内容应基于当前查询结果，具体统计口径由业务需求定义；视觉样式不得因页面不同而变化。

### 12.2 通用交互状态

| 状态 | 规范 |
|---|---|
| Hover | 只改变背景、边框或文字颜色，不引起布局抖动 |
| Focus | 有明确焦点样式，键盘操作时可识别 |
| Disabled | 降低对比度并禁止点击，不仅依靠颜色表达禁用 |
| Loading | 在原内容区域展示加载状态，保持页面结构尺寸稳定 |
| 空数据 | 内容区居中展示；主说明 13px 深灰，辅助说明 12px 浅灰 |
| 长文本 | 单行省略 + Tooltip；需要换行的备注类字段由业务单独定义 |
| 横向溢出 | 限制在状态栏、操作区或表格内部滚动，不撑宽整个页面 |
| 表头吸顶 | 表格内容纵向滚动时保持字段标题可见 |
