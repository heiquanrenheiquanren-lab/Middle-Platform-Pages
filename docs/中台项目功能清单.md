### 1.2 需求类型颜色识别

> 颜色分类依据最新思维导图截图和图 2 的图例。由于 `.mm` 文件本身没有保存颜色属性，以下类型是根据截图高亮结果整理的；如果后续重新导出思维导图，建议同时保留颜色截图或改用带样式的导出格式。

| 颜色 / 标记 | 需求类型 | 文档中的识别口径 |
|---|---|---|
| 无高亮 | 当前版本常规需求 | 图 2 中未使用特殊底色的普通节点 |
| 粉色 | 当前版本变更需求 | 当前版本范围内发生调整的需求 |
| 红色 | 版本补充需求，业务刚需 | 当前版本需要补充，影响业务闭环的需求 |
| 浅蓝色 | 后续版本迭代需求 | 当前版本暂不实现，后续版本规划 |
| 黄绿色 | 待确认需求 | 需要业务确认范围、规则或实现方式 |
| 灰色 | 当前版本删除需求 | 当前版本明确删除或不纳入范围 |

#### 1.2.1 当前版本变更需求（粉色）

- 全局组件：SKU批量精准查询、下载全部查询结果。
- 全局列表交互：SKU左侧显示产品图片，鼠标点击小图，浮窗展示大图，点击空白区域，关闭浮窗；SKU右侧显示组合品标识，鼠标点击图标，浮窗展示组合品SKU、配比数量，点击空白区域，关闭浮窗。
- 库存 / 批次关联：领星采购单号。
- 库存 / 供应商库存 / 货权调整。
- 备货需求 / 销量预测审批：团队负责人审批。
- 发货计划：运输方式、体积重。
- 发货计划 / 计划号关联 FBA 货件：发货计划列表操作列新增关联 FBA 货件按钮；数据不匹配时单元格提示；修改关联单号。
- 采购单 / 采购单变更：采购计划-计划交货日期。
- 供应商库存 / 收货批次：批次待发数 = 计划号被创建发货单的申报数。
- 组合品加工：子件数量脱离组合品单独发货。

#### 1.2.2 版本补充需求，业务刚需（红色）

- 供应商资料 / 基础资料 / 合作状态：开发中、黑名单不可在任何单据中被查找和选中。
- 仓库资料：仓库类型、基础资料。
- 供应商库存 / 批次费用分摊 / 头程物流费用：一票多件、按方。
- ERP协同 / 仓库料号匹配：FNSKU、海外仓料号。

#### 1.2.3 后续版本迭代需求（浅蓝色）

- SKU资料：SKU编码自动生成、中台创建 SKU 同步到易仓 / 领星 ERP 创建。
- SKU资料：辅料包材。
- SKU资料 / 采购资料：弹窗查看历史采购单价明细、弹窗查看历史采购单价波动趋势、近一年采购单价加权平均。
- 全局设定：供应商资料、新报价审批、服务商资料、仓租计费方式。
- 平台管理：审批与之相关的 SellerSKU 资料。
- 库存：显示 / 隐藏销量趋势、按自定义日期导出库存报表。
- 库存 / 库内加工：为组合品添加辅料包材 SKU；按配比消耗辅料包材；辅料包材 SKU 采购成本计入加工费（辅料包材）。
- 平台仓海外仓库存 / 货权调整：货权调整、在途货权通过发货单进行货权调整。
- 备货计划：SKU维度备货计划汇总统计。
- 采购计划：带入 SKU 关联辅料包材（产品包装）；当一个 SKU 有多个供应商时，可选中一个作为计划供应商；按被选中的供应商带入供应商料号、交期、最小起订量、包装、箱规。
- 采购单：选择供应商料号资料中供应商报价，默认取上一次报价；点击图标，展示采购单价变动趋势；提交时同步增加供应商料号报价；辅料包材自动关联与成本核算。
- 采购计划：SKU维度采购计划汇总统计。

#### 1.2.4 待确认需求（黄绿色）

- 全局组件：导出工作台，记录文件生成队列和导出日志。
- 团队库存：订单场景中仅扣减团队库存，团队库存不足时订单库存状态显示为团队库存不足并高亮展示。
- 供应商资料：报价附件。
- 库存：平台仓海外仓合租计算（按库龄）。
- 备货需求：支持按预算目标填报每月销量预测。
- 供应商库存：VMI由供应商提报库存更新。
- 供应商库存 / 货权调整：发货单货权调整。
- 发货计划费用字段计算：后续版本维护基本资料后，将更精确计算。
- 采购单变更：后续版本需求，可变更采购仓，由此已产生的全部供应商库存数据同步变化；后续版本需求，可变更 SKU 采购数量，由此已产生的全部供应商库存数据同步变化。

#### 1.2.5 当前版本删除需求（灰色）

- 备货需求 / 批量操作：批量加入备货需求清单。

    - 显示/隐藏货值

      - 上升（>0）显示为红色
      - 下降（<0）显示为绿色
- 财务
  - 供应商库存在库货值计算
    - 场景
      - 供应商仓
        - 入库成本=净采购成本+产品包装分摊+采购运费分摊+入库费分摊+库内加工费分摊
          - 产品包装
            - 供应商待采或委外包装产生的费用，按月填报，按收货批次分摊
          - 采购运费
            - 无，计0
          - 入库费
            - 无，计0
          - 库内加工费
            - 无，计0
      - 合作仓（佳士精密仓）
        - 入库成本=净采购成本+产品包装分摊+采购运费分摊+入库费分摊+库内加工费分摊
          - 产品包装
            - 供应商待采或委外包装产生的费用，按月填报，按收货批次分摊
          - 采购运费
            - 供应商生产后发货到佳士精密仓，按日期填报，按收货批次分摊
          - 入库费
            - 按月填报，按收货批次分摊
          - 库内加工费
            - 按月填报，按收货批次分摊
      - 自营仓
        - 暂无（系统暂不支持该场景汇算）
    - 计算
      - 采购成本（净成本）=采购单价（含税/未税）+产品包装分摊
        - 采购单价（含税/未税）=产品裸价
          - 采购单下单单价
        - 产品包装分摊
          - 按数量
            - 单个SKU分摊额 = (当月辅料包材总费用 / 当月所有交货SKU总数量) × 该SKU当月交货数量
          - 按金额
            - 单个SKU分摊额 = (该SKU裸价总成本 / 当月所有交货SKU裸价总成本) × 当月辅料包材总费用
      - 入库成本=采购成本+产品包装分摊+采购运费分摊+入库费分摊+库内加工费分摊
        - 采购运费分摊
          - 按数量
            - 单个SKU分摊额 = (该批次运费 / 该批次SKU总数量) × 该SKU在该批次的数量
          - 按重量
            - 单个SKU分摊额 = (该批次运费 / 该批次SKU总重量) × 该SKU在该批次的重量
        - 入库费分摊
          - 按数量
            - 单个SKU分摊额 = (当月其他入库总费用 / 当月所有入库SKU总数量) × 该SKU当月入库数量
          - 按金额
            - 单个SKU分摊额 = (该SKU裸价总成本 / 当月所有入库SKU裸价总成本) × 当月其他入库总费用
        - 库内加工费分摊
          - 按数量
            - 单个SKU分摊额 = (当月库内加工总费用 / 当月所有加工单SKU总加工数量) × 该SKU在加工单中的数量
          - 按金额
            - 单个SKU分摊额 = (该SKU裸价成本 / 参与加工的所有SKU裸价总成本) × 当月库内加工总费用
      - 供应商库存在库货值=Σ每SKU入库成本*在库数量
  - 平台仓海外仓在库货值计算
    - 出库成本=入库成本+提货运费分摊+出库费分摊+物流加工费分摊
      - 提货运费分摊
        - 按数量
          - 单个SKU分摊额 = (当月提货运费总额 / 当月所有提货SKU总数量) × 该SKU当月提货数量
        - 按重量
          - 单个SKU分摊额 = (当月提货运费总额 / 当月所有提货SKU总重量) × 该SKU当月提货重量
      - 出库费分摊
        - 按数量
          - 单个SKU分摊额 = (当月其他出库总费用 / 当月所有出库SKU总数量) × 该SKU当月出库数量
        - 按金额
          - 单个SKU分摊额 = (该SKU裸价总成本 / 当月所有出库SKU裸价总成本) × 当月其他出库总费用
      - 物流加工费分摊
        - 按数量
          - 单个SKU分摊额 = (当月物流加工总费用 / 当月头程加工单SKU总数量) × 该SKU在头程加工单中的数量
        - 按金额
          - 单个SKU分摊额 = (该SKU裸价成本 / 头程加工的所有SKU裸价总成本) × 当月物流加工总费用
    - 头程成本=头程物流费用+清关税费+其他头程费用
      - 头程物流费用
        - 一票一件
          - 头程物流费用（填写）=计费重*发货数量*单价
            - 按数量
              - 按单价计费
        - 一票多件
          - 头程物流费用（填写）=Σi计费重i*发货数量i*单价i
            - 按计费重
              - 单个SKU分摊额 = (发货单物流费用总额 / 所有发货SKU总计费重) × 该SKU计费重
            - 按方
              - 单个SKU分摊额 = (发货单物流费用总额 / 所有发货SKU装箱总体积) × 该SKU体积
      - 清关税费/其他头程费用
        - 一票一件
          - 清关税费/其他头程费用（填写）
            - 按计费重
              - 单个SKU分摊额 = (发货单费用总额 / 所有发货SKU总计费重) × 该SKU计费重
        - 一票多件
          - 清关税费/其他头程费用（填写）
            - 按计费重
              - 单个SKU分摊额 = (发货单费用总额 / 所有发货SKU总计费重) × 该SKU计费重
    - 到岸成本=出库成本+头程成本
    - 平台仓海外仓在库货值=Σ每SKU到岸成本*在库数量
    - 物流对账
      - 预估头程物流费用
        - 展示实重，体积，体积重，计费重，单价，头程物流费用差值
      - 实际头程物流费用（账单导入）
        - 按实际物流费用请款
  - 平台仓海外仓仓租计算（按库龄）
    - 配置不同海外仓/平台仓免租期
    - 配置海外仓/平台仓仓租计费方式
    - 按收货批次开始计算在库库龄
    - 超免租期库存首日起计算仓租，按计费方式，阶梯累加仓租费
    - 仓储对账
      - 预估仓租费
        - 展示差值
      - 实际仓租费（账单导入）
        - 按实际仓租请款
  - 按自定义日期导出库存报表
    - 导出字段
      - SKU编码
      - 品名
      - 品牌
      - 类别
        - 一级类别
        - 二级类别
      - 团队
      - 仓库名称
      - 仓库编码
      - 库存数量
      - 货值
    - 统计字段
      - 总库存（账面库存）
      - 可用库存
        - 可用库存=总库存-订单锁库-发货单占用
      - 不良品/报废库存
- 运营
  - 库存查询（团队权限）
    - 按SKU+团队查看全局库存
    - 按SKU+团队+仓库查看库存，库龄

| 提货仓（发货单可发货） | 增加 |
| 提货仓（可加工） | 增加 |
| 采购对账可对账批次条数 | 增加 |
- 库存统计
  - 供应商库存，在库
    - 分仓
      - 采购单收货，按收货批次计数，入采购仓，按SKU求和
  - 供应商库存，在产=采购单在途
    - 采购单PO创建，未收货
  - 供应商库存，在库待发
    - 发货单创建，发货仓为供应商仓库，未提货
- 库龄统计
  - 按采购单收货批次，收货日计数为库龄1天
  - 不计算仓租费
  - 查询列表按SKU+团队+仓库维度，统计在库龄段内的数量求和（0~30~60~90~180~日）
- 库内加工
  - 加工单加载待加工组合品
    - 任意子件在库量为0时，不加载该组合品
  - 为组合品添加辅料包材SKU
    - 填入每件辅料包材消耗配比
  - 输入组合品加工数量
    - 关联组合品采购计划，展示计划加工数量
    - 子件自动按配比数量填入
      - 最大不超过组合品可加工数量
    - 子件团队库存不足时调用同仓公共库存加工
  - 完成加工
    - 按配比扣减子件在库数量
    - 按加工数增加组合品库存数量
    - 按配比消耗辅料包材
      - 辅料包材SKU采购成本计入加工费（辅料包材）
  - 交互
    - 加工单内模糊搜索SKU、品名、计划号
  - 子件数量脱离组合品单独发货
    - 库内将A团队组合品(M)子件(M1)货权调整到B团队
    - A团队组合品(M)可加工数量减少，(M1)在库数量减少；B团队获得(M1)独立库存（不获得组合品M库存）
    - B团队库存M1提货到发货单执行发货
    - 其他计划中的M1入库时，可调拨给A团队，优先补齐原A团队计划中的可加工数量
- VMI由供应商提报库存更新
  - 独立VMI网页
  - 用准确供应商名称免密登入
  - 上传excel
    - SKU
    - 数量
  - 收货单预览解析
  - 采购单待收SKUFIFO自动填入收货数量
  - 确认收货并产生新的收货批次
  - 货权调整（见下表）

#### 供应商库存货权调整规则

| 项目 | 规则 |
|---|---|
| 操作 | 搜索 SKU，选择来源团队和调入团队，输入调整数量后提交 |
| 库存结果 | 来源团队在库减少，调入团队在库增加 |
| 在库货权 | 仅可调整在库货权 |
| 在途货权 | 通过采购单进行货权调整 |
| 发货单货权 | 支持发货单货权调整 |
- 仓库费用分摊
  - 选择费用类型
    - 库内加工费分摊
      - 按数量
        - 单个SKU分摊额 = (当月库内加工总费用 / 当月所有加工单SKU总加工数量) × 该SKU在加工单中的数量
      - 按金额
        - 单个SKU分摊额 = (该SKU裸价成本 / 参与加工的所有SKU裸价总成本) × 当月库内加工总费用
    - 出库费分摊
      - 按数量
        - 单个SKU分摊额 = (当月其他出库总费用 / 当月所有出库SKU总数量) × 该SKU当月出库数量
      - 按金额
        - 单个SKU分摊额 = (该SKU裸价总成本 / 当月所有出库SKU裸价总成本) × 当月其他出库总费用
  - 填入金额
  - 选择费用周期（一般为一个月）
  - 填入负责人
  - 附件和备注
  - 选择费用周期内的收货批次
  - 提交，完成分摊
    - 被分摊的收货批次，对应的费用项字段下赋分摊金额
    - 该批次下单个SKU分摊额=该批次分摊金额/批次收货数量
    - 加工费完成分摊后，在物流加工即无法加工，也无法参与二次分摊（该条数据在物流加工，头程费用分摊无法被查询和展示）
- 交互组件
  - 显示/隐藏货值

#### 字段与计算规则

| 字段 | 规则/选项 |
|---|---|
| 发货仓 | 供应商仓库、自营仓 |
| 目的地仓 | 海外仓、平台仓 |
| 发货方式 | 必填 |
| 运输方式 | 空运（5000）、海运（6000）、国内小包（8000） |
| 预计物流时效 | 用于计算预计到货日期 |
| 预计发货日期 | 计划字段 |
| 预计到货日期 | =预计发货日期 + 预计物流时效 |
| 计划发货数量 | 计划发货数量 |
| 总体积 | =计划发货数量 × 体积 |
| 总重量 | =计划发货数量 × 箱规（重） |
| 体积重 | 空运=体积/5000；海运=体积/6000；国内小包=体积/8000 |
| 总体积重 | =计划发货数量 × 体积重 |
| 箱数 | 计划发货数量/箱规，向上取整；不足整箱时同步向上调整计划发货数量 |

| 版本 | 规则 |
|---|---|
| 当前版本 | 填入预计物流单价；发货计划物流费用 = 预计发货数量 × 总计费重 × 预计物流单价 |
| 后续版本 | 完善头程服务商报价表和更详细的物流方式后，再进行精确计算 |

        - 收货人
      - 批次采购数=批次到货数=收货数量
      - 批次在途数=0
      - 批次待发数=计划号被创建发货单的申报数
      - 批次费用分摊金额小计=Σ批次每SKU分摊额
  - 结束收货
    - 采购单状态已完成
    - 采购单在途数清零
      - 包含的全部采购计划在途数清零
    - 采购单采购数不变，到货数不变
    - 供应商库存中，在途/在产数清零，总数减少
- 货权调整
  - 交互流程
    - 打开货权调整清单
    - 查询要调整的计划号（增加搜索栏）
    - 勾选要调整的计划号
    - 选择调入平台/店铺，关联店铺责任团队，选择调入sellerSKU
    - 输入调入数量
    - 点击提交
  - 数据链路
    - 采购单数据
      - 原采购单是否包含调入团队采购计划
        - 是
          - 采购单计划号不变，调出团队采购数、在途数减少；调入团队采购数、在途数增加
        - 否
          - 采购单新增一条调入团队采购计划号，调出团队采购数、在途数价绍；调入团队采购数、在途数增加
    - 供应商库存数据
      - 调出团队在途减少，总量减少；调入团队在途增加，总量增加
- 采购费用分摊
  - 交互流程
    - 打开费用分摊
    - 选择费用类型
    - 输入费用金额
    - 选择费用周期
    - 选择分摊规则
    - 选择负责人
    - 上传附件，填写备注（选填）
    - 查询收货批次（在费用周期内的收货批次）
    - 点击提交，完成分摊
  - 产品包装分摊
    - 按数量
      - 单个SKU分摊额 = (当月辅料包材总费用 / 当月所有交货SKU总数量) × 该SKU当月交货数量
    - 按金额
      - 单个SKU分摊额 = (该SKU裸价总成本 / 当月所有交货SKU裸价总成本) × 当月辅料包材总费用
  - 采购运费分摊
    - 按数量
      - 单个SKU分摊额 = (该批次运费 / 该批次SKU总数量) × 该SKU在该批次的数量
    - 按重量
      - 单个SKU分摊额 = (该批次运费 / 该批次SKU总重量) × 该SKU在该批次的重量
  - 入库费分摊
    - 按数量
      - 单个SKU分摊额 = (当月其他入库总费用 / 当月所有入库SKU总数量) × 该SKU当月入库数量
    - 按金额
      - 单个SKU分摊额 = (该SKU裸价总成本 / 当月所有入库SKU裸价总成本) × 当月其他入库总费用
- 收货批次
  - 提交收货时创建收货批次，在供应商库存可按批次查询
  - 数据记录
    - 收货时间
    - 收货数量
    - 收货人
    - 批次采购数=批次到货数=收货数量
    - 批次在途数=0
    - 批次待发数=计划号被创建发货单的申报数
    - 批次费用分摊金额小计=Σ批次每SKU分摊额
- 采购单变更
  - 可变更字段
    - 联系人
    - 联系方式
    - 采购负责人
    - 采购主体
    - 附件
    - 备注
    - 结算方式
    - 预付比例
    - 结算币种
    - 采购计划-计划交货日期
  - 不可变更字段
    - 供应商
    - 采购仓
      - 后续版本需求：可变更采购仓，由此已产生的全部供应商库存数据同步变化
    - SKU
    - SKU采购数量
      - 后续版本需求：可变更SKU采购数量，由此已产生的全部供应商库存数据同步变化
    - 是否含税
