### 1.2 需求类型颜色识别

> 颜色分类依据最新思维导图截图和图 2 的图例。由于 `.mm` 文件本身没有保存颜色属性，以下类型是根据截图高亮结果整理的；如果后续重新导出思维导图，建议同时保留颜色截图或改用带样式的导出格式。

| 颜色 / 标记 | 需求类型 | 文档中的识别口径 |
|---|---|---|
| 无高亮 | 当前版本常规需求 | 图 2 中未使用特殊底色的普通节点 |
| 粉色 | 当前版本变更需求 | 当前版本范围内发生调整的需求 |
| 红色 | 版本补充需求，业务刚需 | 当前版本需要补充，影响业务闭环的需求 |
| 浅蓝色 | 后续版本迭代需求 | 当前版本暂不实现，后续版本规划 |
| 黄绿色 | 待确认需求 | 需要业务确认范围、规则或实现方式 |
| 灰色 | 当前版本删除需求 | 当前版本明确删除或不纳入范围 |

#### 1.2.1 当前版本变更需求（粉色）

- 全局组件：SKU批量精准查询、下载全部查询结果。
- 全局列表交互：SKU左侧显示产品图片，鼠标点击小图，浮窗展示大图，点击空白区域，关闭浮窗；SKU右侧显示组合品标识，鼠标点击图标，浮窗展示组合品SKU、配比数量，点击空白区域，关闭浮窗。
- 库存 / 批次关联：领星采购单号。
- 库存 / 供应商库存 / 货权调整。
- 备货需求 / 销量预测审批：团队负责人审批。
- 发货计划：运输方式、体积重。
- 发货计划 / 计划号关联 FBA 货件：发货计划列表操作列新增关联 FBA 货件按钮；数据不匹配时单元格提示；修改关联单号。
- 采购单 / 采购单变更：采购计划-计划交货日期。
- 供应商库存 / 收货批次：批次待发数 = 计划号被创建发货单的申报数。
- 组合品加工：子件数量脱离组合品单独发货。

#### 1.2.2 版本补充需求，业务刚需（红色）

- 供应商资料 / 基础资料 / 合作状态：开发中、黑名单不可在任何单据中被查找和选中。
- 仓库资料：仓库类型、基础资料。
- 供应商库存 / 批次费用分摊 / 头程物流费用：一票多件、按方。
- ERP协同 / 仓库料号匹配：FNSKU、海外仓料号。

#### 1.2.3 后续版本迭代需求（浅蓝色）

- SKU资料：SKU编码自动生成、中台创建 SKU 同步到易仓 / 领星 ERP 创建。
- SKU资料：辅料包材。
- SKU资料 / 采购资料：弹窗查看历史采购单价明细、弹窗查看历史采购单价波动趋势、近一年采购单价加权平均。
- 全局设定：供应商资料、新报价审批、服务商资料、仓租计费方式。
- 平台管理：审批与之相关的 SellerSKU 资料。
- 库存：显示 / 隐藏销量趋势、按自定义日期导出库存报表。
- 库存 / 库内加工：为组合品添加辅料包材 SKU；按配比消耗辅料包材；辅料包材 SKU 采购成本计入加工费（辅料包材）。
- 平台仓海外仓库存 / 货权调整：货权调整、在途货权通过发货单进行货权调整。
- 备货计划：SKU维度备货计划汇总统计。
- 采购计划：带入 SKU 关联辅料包材（产品包装）；当一个 SKU 有多个供应商时，可选中一个作为计划供应商；按被选中的供应商带入供应商料号、交期、最小起订量、包装、箱规。
- 采购单：选择供应商料号资料中供应商报价，默认取上一次报价；点击图标，展示采购单价变动趋势；提交时同步增加供应商料号报价；辅料包材自动关联与成本核算。
- 采购计划：SKU维度采购计划汇总统计。

#### 1.2.4 待确认需求（黄绿色）

- 全局组件：导出工作台，记录文件生成队列和导出日志。
- 团队库存：订单场景中仅扣减团队库存，团队库存不足时订单库存状态显示为团队库存不足并高亮展示。
- 供应商资料：报价附件。
- 库存：平台仓海外仓合租计算（按库龄）。
- 备货需求：支持按预算目标填报每月销量预测。
- 供应商库存：VMI由供应商提报库存更新。
- 供应商库存 / 货权调整：发货单货权调整。
- 发货计划费用字段计算：后续版本维护基本资料后，将更精确计算。
- 采购单变更：后续版本需求，可变更采购仓，由此已产生的全部供应商库存数据同步变化；后续版本需求，可变更 SKU 采购数量，由此已产生的全部供应商库存数据同步变化。

#### 1.2.5 当前版本删除需求（灰色）

- 备货需求 / 批量操作：批量加入备货需求清单。

#### 财务核算

#### 供应商库存货值

| 仓库场景 | 入库成本口径 | 费用来源/处理 |
|---|---|---|
| 供应商仓 | 净采购成本 + 产品包装分摊 + 采购运费分摊 + 入库费分摊 + 库内加工费分摊 | 产品包装按月填报并按收货批次分摊；采购运费、入库费、库内加工费暂为 0 |
| 合作仓（佳士精密仓） | 净采购成本 + 产品包装分摊 + 采购运费分摊 + 入库费分摊 + 库内加工费分摊 | 产品包装按月填报；采购运费按日期填报；入库费、库内加工费按月填报，均按收货批次分摊 |
| 自营仓 | 暂不汇算 | 系统暂不支持该场景 |

#### 供应商库存成本公式

| 计算项 | 公式/规则 |
|---|---|
| 采购成本（净成本） | 采购单价（含税/未税） + 产品包装分摊；采购单价取采购单下单单价 |
| 产品包装分摊（按数量） | （当月辅料包材总费用 / 当月所有交货 SKU 总数量）× 该 SKU 当月交货数量 |
| 产品包装分摊（按金额） | （该 SKU 裸价总成本 / 当月所有交货 SKU 裸价总成本）× 当月辅料包材总费用 |
| 采购运费分摊（按数量） | （该批次运费 / 该批次 SKU 总数量）× 该 SKU 在该批次的数量 |
| 采购运费分摊（按重量） | （该批次运费 / 该批次 SKU 总重量）× 该 SKU 在该批次的重量 |
| 入库费分摊（按数量） | （当月其他入库总费用 / 当月所有入库 SKU 总数量）× 该 SKU 当月入库数量 |
| 入库费分摊（按金额） | （该 SKU 裸价总成本 / 当月所有入库 SKU 裸价总成本）× 当月其他入库总费用 |
| 库内加工费分摊（按数量） | （当月库内加工总费用 / 当月所有加工单 SKU 总加工数量）× 该 SKU 在加工单中的数量 |
| 库内加工费分摊（按金额） | （该 SKU 裸价成本 / 参与加工的所有 SKU 裸价总成本）× 当月库内加工总费用 |
| 供应商库存在库货值 | Σ 每 SKU 入库成本 × 在库数量 |

#### 平台仓/海外仓库存货值

| 计算项 | 公式/规则 |
|---|---|
| 出库成本 | 入库成本 + 提货运费分摊 + 出库费分摊 + 物流加工费分摊 |
| 提货运费分摊（按数量） | （当月提货运费总额 / 当月所有提货 SKU 总数量）× 该 SKU 当月提货数量 |
| 提货运费分摊（按重量） | （当月提货运费总额 / 当月所有提货 SKU 总重量）× 该 SKU 当月提货重量 |
| 出库费分摊（按数量） | （当月其他出库总费用 / 当月所有出库 SKU 总数量）× 该 SKU 当月出库数量 |
| 出库费分摊（按金额） | （该 SKU 裸价总成本 / 当月所有出库 SKU 裸价总成本）× 当月其他出库总费用 |
| 物流加工费分摊（按数量） | （当月物流加工总费用 / 当月头程加工单 SKU 总数量）× 该 SKU 在头程加工单中的数量 |
| 物流加工费分摊（按金额） | （该 SKU 裸价成本 / 头程加工的所有 SKU 裸价总成本）× 当月物流加工总费用 |
| 头程成本 | 头程物流费用 + 清关税费 + 其他头程费用 |
| 到岸成本 | 出库成本 + 头程成本 |
| 平台仓/海外仓在库货值 | Σ 每 SKU 到岸成本 × 在库数量 |

#### 头程费用与对账

| 场景 | 费用计算/分摊 |
|---|---|
| 一票一件：头程物流费用 | 计费重 × 发货数量 × 单价 |
| 一票多件：头程物流费用 | Σi 计费重i × 发货数量i × 单价i；可按计费重或体积分摊 |
| 一票多件：按计费重分摊 | （发货单物流费用总额 / 所有发货 SKU 总计费重）× 该 SKU 计费重 |
| 一票多件：按体积分摊 | （发货单物流费用总额 / 所有发货 SKU 装箱总体积）× 该 SKU 体积 |
| 清关税费/其他头程费用 | 一票一件、一票多件均按计费重分摊；分摊额 = 发货单费用总额 / 所有发货 SKU 总计费重 × 该 SKU 计费重 |
| 预估头程物流费用 | 展示实重、体积、体积重、计费重、单价、头程物流费用差值 |
| 实际头程物流费用 | 账单导入，按实际物流费用请款 |

| 输入加工数量 | 关联组合品采购计划并展示计划加工数量；子件按配比自动填入，最大不超过组合品可加工数量 |
| 库存不足 | 子件团队库存不足时，调用同仓公共库存加工 |
| 完成加工 | 按配比扣减子件在库，按加工数增加组合品库存，按配比消耗辅料包材 |
| 成本 | 辅料包材 SKU 采购成本计入加工费（辅料包材） |
| 查询 | 加工单内支持模糊搜索 SKU、品名、计划号 |
| 子件脱离组合品发货 | M1 从 A 团队调整到 B 团队后，A 团队组合品 M 可加工数量和 M1 在库减少；B 团队获得 M1 独立库存，不获得组合品 M 库存 |
| 后续使用 | B 团队 M1 可提货到发货单；其他计划的 M1 入库时可调拨给 A 团队，优先补齐 A 团队原计划可加工数量 |

| 预计发货日期 | 计划字段 |
