# 领星采购单对接 · 风险与待澄清清单

> 本文档用于在正式开发前，梳理「领星采购单对接」需求落地时可能翻车的风险点与必须先澄清的问题。内容是对 PRD 正文的补充，聚焦初始化、切换、逆向流程、状态一致性和库存金额衔接等 PRD 未覆盖的切面。

---

## 一、初始化 / 历史数据迁移（最高优先级）

### 1.1 存量采购单拉不拉、拉多久

- 现状：业务目前在领星直接建采购单，中台没有这些单的记录。
- 风险：如果只同步「以后新建的单」，历史在途、待收货数据会断裂，中台库存与发货计划追溯残缺。
- 建议：按「业务上仍有多少单处于在途/待收货」确定拉取范围，而不是拍脑袋定时长。真正要拉的是**尚未完结的单**；已完成单若无追溯需求可不拉，但只要还有在途、待收货、仍在产生收货的单，就必须拉。

### 1.2 存量单如何与中台已有数据对上（最难）

- 中台已有采购计划、发货计划、供应商库存，与领星存量单是两套数据，**无单据映射**。
- 风险：拉回的领星单靠什么字段与「中台采购计划」对上？SKU？供应商？采购计划号（若领星单未存中台计划号则对不上）？
- 后果：若映射失败，收货回传时无法定位回写到哪个计划行。

### 1.3 数量口径对齐

- 中台供应商库存已有「在途」数据，拉回领星存量单后可能出现「中台在途 100、领星在途 80」的双份口径。
- 需要明确：以谁为准？如何去重？

---

## 二、切换期的「双轨并行」风险

- 现状：以前业务在领星建单，现在改为中台建单再推领星，存在过渡期两套建单方式并存。
- 风险：
  1. 业务习惯性仍在领星直接建单，同时在中台建单 → 同一采购需求产生两张单。
  2. 领星侧无「中台推送 vs 人工创建」标记 → 中台拉数据时把人工单当成自己推的单来映射，直接错乱。
- 建议：必须设定明确**切换时点**，之后只允许中台推单，并对亚马逊团队关闭领星人工建单入口或加标识。

## 三、逆向流程（PRD 目前只覆盖正向，逆向基本空白）

| 逆向场景 | 需明确的问题 |
|---|---|
| 取消采购单 | 中台如何感知？中台采购单是否回退？采购计划、发货计划、供应商库存是否一起回滚？ |
| 审批驳回 | 领星驳回中台推的单后，中台「已推送」还是回退？中台采购单状态如何变？ |
| 删除采购单 | 映射记录、明细、已回写库存如何处理？ |
| 部分/全部退货 | 已收货数量回减后，待收货、在途如何联动？供应商库存是否反向回补？ |
| 变更金额/数量 | 中台采购单金额、SKU 采购资料是否跟着改，还是只记变更单号不重算？ |

若不定义清楚，中台数据会逐步漂移，最终与领星对不上。

## 四、口径矛盾（建议优先澄清）

两处文档对「领星采购单状态」的说法不一致：

- BUSINESS_LOGIC.md 5.6.3：创建接口**直接创建「待到货」**，跳过「待下单 → 待到货」。
- 供应链中台功能清单.md：提交后**同步领星 PO 单号「已审批」**，中台 PO 进入待收货。

**核心问题：领星侧到底有没有审批环节？**

- 若领星建单后需审批才生效，则「直接建待到货」不成立，中间存在「已审批」状态。
- 若领星免审批直接生效，则「同步已审批」的说法不成立。

此问题不定清楚，状态机就是乱的，上下游都会踩坑。

## 五、库存与金额衔接风险

1. **时间差**：推单成功 → 领星审批 → 实际收货，中间可能数天。中台供应商库存「在途」何时起算（推单成功即算，还是领星确认收货才回补在库）？
2. **金额对账**：中台采购单有采购金额、税率、币种、辅料包材费、运费；领星口径是否一致？税、币种、运费谁算？口径不一致则财务对账糊涂。
3. **供应商库存双向联动**：中台建单时在途增加，领星也在算库存，是否会重复累计（延续「领星库存数量很多」的历史隐患）。

---

## 六、权限与操作责任

- 单由中台建，但收货仍在领星操作。需明确：
  - 领星侧收货人是否仍为原业务，账号权限是否调整？
  - 中台侧谁能「推单」「重试」「解除映射」？推错谁负责改？

---

## 七、异常恢复的实操风险

1. **孤儿单**：推单接口成功但中台未及保存映射即挂，领星有单、中台无记录，如何靠查询接口找回补映射？
2. **推送成功但领星后续作废**：中台仍记「已推送」，下次同步如何处理？
3. **补偿机制**：靠定时任务兜底还是消息队列/事件驱动？数据延迟多久业务可接受？

---

## 优先澄清清单（按「不定清楚不能开工」排序）

1. 领星采购单是否有审批流（决定状态机，见第四点矛盾）。
2. 存量单初始化范围 + 映射关系（靠什么字段对上中台采购计划）。
3. 切换时点和双轨处理（哪天起只允许中台推，领星人工建单入口如何处理）。
4. 逆向流程清单（取消/驳回/删除/退货/变更，逐一明确回写与回滚）。
5. 库存与金额的时间口径和归集规则（在途何时起算、金额以谁为准）。
