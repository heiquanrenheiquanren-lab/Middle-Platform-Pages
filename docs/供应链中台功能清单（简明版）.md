# 供应链中台功能清单（简明版）

> 本文档是面向产品、业务、研发和管理人员的阅读版功能地图。
>
> 它回答“供应链中台能做什么、各模块如何衔接”，不展开字段清单、计算公式、接口字段和逐条校验规则。
>
> 详细规则仍以 [供应链中台功能清单.md](./供应链中台功能清单.md)、[BUSINESS_LOGIC.md](./BUSINESS_LOGIC.md) 和对应 PRD 为准。

## 一、系统定位

供应链中台用于把商品、供应商、库存、计划、采购和物流履约串成一条可追踪的业务链路：

```text
基础资料 → 需求预测 → 备货计划 → 采购计划 → 采购单 → 供应商库存
                                      ↓
                                发货计划 → 发货单 → 平台仓/海外仓库存
```

| 核心目标 | 说明 |
|---|---|
| 计划可执行 | 明确要买什么、买多少、什么时候买、从哪里买。 |
| 库存可追踪 | 知道货物处于在途、供应商仓、待发、物流中还是目的仓。 |
| 数据口径统一 | 采购、物流、库存和财务使用同一套单据、批次和数量口径。 |
| 过程可追溯 | 计划、采购、提货、发货、收货和费用变化均保留记录。 |

## 二、功能地图

| 业务区域 | 解决的问题 | 主要能力 | 当前项目页面 |
|---|---|---|---|
| 基础资料 | 系统中的商品、供应商、仓库和平台信息从哪里来 | 维护主数据、关系映射、业务状态和权限 | 作为各业务页面的基础能力 |
| 库存管理 | 现在有多少货、货在哪里、属于谁、放了多久 | 团队库存、供应商库存、平台仓/海外仓库存、库龄和货值 | 供应商库存；团队库存、平台仓/海外仓为规划能力 |
| 需求与计划 | 未来需要多少货，如何安排采购和发货 | 需求预测、备货计划、采购计划、发货计划 | 需求预测、备货计划、采购计划、发货计划 |
| 采购执行 | 采购计划如何变成真实采购，货什么时候到 | 采购单、审批、ERP 协同、收货、变更、费用分摊 | 采购单 |
| 物流履约 | 货物如何从供应商仓运到目的仓 | 发货单、提货、组合品加工、发货、收货、差异和日志 | 发货单 |
| 成本与对账 | 每批货的采购、仓储和头程成本是多少 | 费用导入、费用分摊、库存货值、单位头程成本查询 | 发货单；SKU 单位头程成本 |

## 三、基础资料与公共能力

### 3.1 商品与 SKU

维护全链路使用的商品主数据，并建立中台 SKU 与外部编码之间的关系。

| 能力类别 | 主要内容 | 业务用途 |
|---|---|---|
| 商品基础资料 | 名称、图片、品牌、型号、分类、产品类型、销售状态 | 统一商品识别和业务查询 |
| 单品与组合品 | 组合品维护子 SKU 及配比 | 支撑采购拆分和物流加工 |
| 规格资料 | 产品尺寸、包装尺寸、重量、箱规 | 支撑采购数量、装箱和物流费用 |
| 采购资料 | 供应商、供应商料号、交期、最小起订量、报价、历史价格 | 支撑采购计划和采购单 |
| 编码映射 | 易仓 SKU、领星 SKU、供应商料号、仓库 SKU、FNSKU、ASIN、SellerSKU | 连接中台与外部系统 |
| 报关与负责人 | 报关信息、产品负责人、采购负责人、计划负责人、运营负责人 | 支撑报关、审批和责任追踪 |

### 3.2 供应商资料

| 能力类别 | 主要内容 | 业务用途 |
|---|---|---|
| 基础信息 | 供应商、联系人、经营资质、付款信息 | 支撑供应商准入和采购执行 |
| 报价管理 | 报价、结算方式、币种、税点、信用额度、报价附件 | 形成可选的采购价格 |
| SKU 关系 | 供应商料号与中台 SKU 配对 | 确认采购商品和供应商编码 |
| 报价审批 | 报价提报、审批、驳回和生效 | 未通过审批的报价不能用于正式采购 |
| 合作状态 | 开发中、合作中、黑名单等 | 不可用供应商不出现在单据选择范围内 |

### 3.3 仓库与物流服务商资料

| 能力类别 | 主要内容 |
|---|---|
| 仓库资料 | 供应商仓库、物流中转仓、自营仓、海外仓、平台仓及其地址、负责人和仓库 SKU |
| 仓储规则 | 仓租计费方式、免租期、库龄区间和仓租单价 |
| 服务商资料 | 头程服务商、海外仓服务商、联系人、结算资料和账单资料 |

### 3.4 平台、店铺与权限

| 能力类别 | 主要内容 |
|---|---|
| 平台与店铺 | 平台、店铺、SellerSKU/ASIN、店铺所属团队、运营负责人 |
| 商品映射 | 中台 SKU 与平台商品的映射关系 |
| 数据权限 | 按团队、角色和组织控制数据查看范围 |
| 操作权限 | 控制计划、采购、物流、库存等业务操作权限 |
| 审批权限 | 支持供应链负责人、部门负责人和管理人员审批 |

### 3.5 公共列表能力

| 能力 | 说明 |
|---|---|
| 查询与筛选 | 条件筛选、模糊搜索、SKU 批量查询 |
| 展示配置 | 列配置、字段显示/隐藏、父子行展示、表头提示 |
| 数据操作 | 刷新、导出、批量操作、单元格编辑 |
| 信息增强 | 产品图片、组合品信息、ERP 关联单据 |
| 过程留痕 | 关键业务操作记录日志 |

## 四、库存管理

### 4.1 团队库存与全局库存

团队库存是库存管理的总览入口，帮助业务从 SKU、团队和仓库多个角度查看库存。

| 能力 | 说明 |
|---|---|
| 库存总览 | 查看全局库存、团队库存、公共库存和仓库库存 |
| 库存状态 | 区分在库、在途、待发和发货单占用 |
| 库龄与销量 | 查看库龄、销量、日均销量和库存周转 |
| 风险识别 | 识别安全、风险、缺货状态，辅助判断补货优先级 |
| 备货联动 | 从风险或缺货 SKU 直接进入备货需求 |
| 团队维度 | 以团队为主要统计维度，公共库存作为可调拨的特殊团队 |

### 4.2 供应商库存

供应商库存用于管理“已经采购但仍在供应商或合作仓”的货物。

| 能力 | 说明 |
|---|---|
| 库存查询 | 按 SKU、团队、供应商和仓库查看库存数量与库龄 |
| 批次追踪 | 关联采购单、采购计划、收货批次、提货批次和费用分摊 |
| 收货管理 | 采购单创建后形成在途/在产库存，收货后转为在库库存，并生成收货批次 |
| 提货管理 | 将货物转入提货仓、物流中转仓或可加工库存 |
| 库内加工 | 按 BOM 消耗子 SKU 和辅料包材，形成组合品库存 |
| 货权调整 | 支持在库货权调整；在途货权通过采购单处理 |
| 费用分摊 | 支持采购运费、入库费、库内加工费和产品包装费用分摊 |
| VMI 协同 | 预留供应商文件上传、收货预览和确认收货能力 |

### 4.3 平台仓与海外仓库存

| 能力 | 说明 |
|---|---|
| 目的仓库存 | 按 SKU、团队、仓库和批次查看在库、在途和库龄 |
| 入库批次 | 发货单收货后生成目的仓入库批次，库存从在途转为在库 |
| 物流关联 | 查看发货单、收货批次、物流费用、清关税费和其他头程费用 |
| 货权管理 | 支持海外仓/平台仓的货权调整和库存归属管理 |
| 仓租管理 | 根据仓库规则计算免租期、库龄和仓租费用 |
| 成本报表 | 支持库存货值、到岸成本、仓储对账和库存报表 |

## 五、需求与计划管理

### 5.1 需求预测

| 能力 | 说明 |
|---|---|
| 预测维护 | 按平台、店铺、国家、团队和 SKU 维护月度销量预测 |
| 预测流程 | 支持预测批次、草稿、提交、确认和作废 |
| 计划联动 | 预测确认后生成备货计划，并保留关联关系 |
| 批量处理 | 支持导入、导出和批量操作 |

### 5.2 备货计划

| 能力 | 说明 |
|---|---|
| 需求汇总 | 汇总需求预测、当前库存、在途库存和安全库存 |
| 备货建议 | 形成 SKU 维度的建议备货数量、需求缺口和期望交货时间 |
| 计划制定 | 按团队、平台、店铺、国家和仓库制定备货安排 |
| 计划流程 | 支持审批、确认、作废和批量生成采购计划 |
| 库存联动 | 从库存风险结果快速创建备货需求 |

### 5.3 采购计划

| 能力 | 说明 |
|---|---|
| 采购安排 | 按 SKU、团队、供应商和采购仓安排采购数量 |
| 资料带入 | 带入供应商、供应商料号、交期、起订量、箱规和参考价格 |
| 日期管理 | 管理计划下单日期和计划交货日期 |
| 组合品拆分 | 按 BOM 拆分为子 SKU 采购计划，父级不直接生成采购金额 |
| 数量校验 | 根据箱规、最小起订量和交期提供数量或日期提示 |
| 批量操作 | 支持整列编辑、批量确认、批量作废和批量生成采购单/发货计划 |
| 采购预览 | 按供应商整理采购内容，支持暂存后继续编辑 |

### 5.4 发货计划

| 能力 | 说明 |
|---|---|
| 物流安排 | 维护发货仓、目的仓、发货方式、运输方式和预计发/到货时间 |
| 费用预估 | 根据 SKU 规格、箱规和运输方式估算箱数、体积、重量和物流费用 |
| 资料关联 | 关联采购计划、采购单、团队库存、仓库料号和物流资料 |
| 计划流程 | 支持单个或批量新建、确认、作废和生成发货单 |
| FBA 关联 | 亚马逊团队支持关联 FBA 货件，并提示关键资料不匹配 |
| 履约衔接 | 确认后进入发货单执行，以计划号作为上下游关联依据 |

| 状态同步 | 同步采购单号、审批状态和收货结果 |

## 七、物流履约与发货单

### 7.1 发货单定位

发货单是从供应商仓或其他发货仓到平台仓/海外仓的履约执行单据，承接发货计划并记录实物履约过程。

| 核心对象 | 说明 |
|---|---|
| 发货单 | 一张发货单可以包含多个 SKU |
| 发货单 SKU 明细 | 每个 SKU 对应一个发货计划 |
| 履约数量 | 保存计划、申报、提货、加工、发货和收货数量 |
| 履约记录 | 保存提货、加工、发货、收货批次及操作日志 |

### 7.2 发货单主要功能

| 履约环节 | 主要能力 |
|---|---|
| 查询与创建 | 查询单据、计划、SKU、仓库、平台、店铺、物流渠道和状态；新建草稿并选择多个 SKU |
| 混单校验 | 校验目的仓、平台类型和发货计划关联关系，避免不允许的混单 |
| 提货 | 记录每个 SKU 的提货数量、提货仓、差异原因和提货批次 |
| 组合品加工 | 根据子 SKU 可用库存和 BOM 配比完成加工，记录加工批次及子件消耗 |
| 发货 | 记录实际发货数量、少发原因、物流信息和发货批次 |
| 收货 | 记录实际收货数量、少收情况、目的仓入库批次和物流状态 |
| 数量调整 | 在允许状态下调整提货、发货或收货数量，并保留调整原因和日志 |
| 手动完结 | 在待收货或部分收货场景下结束单据，保留未收数量差异 |
| 详情追踪 | 查看差异明细、履约批次、物流轨迹、费用、箱信息和操作日志 |
| 费用与导出 | 导入物流费用和轨迹，分摊其他头程费用并导出数据 |
| 数据联动 | 发货、收货、作废、取消和费用动作联动库存、计划、批次和成本 |

### 7.3 发货单状态主线

```text
草稿 → 待提货 → 可加工 → 待发货 → 待收货 → 部分收货 → 已完成
  └→ 已作废                         └→ 已取消（待提货阶段）
```

| 状态规则 | 说明 |
|---|---|
| 组合品流转 | 含组合 SKU 的单据提货完成后先进入“可加工”；普通 SKU 单据可直接进入“待发货” |
| 差异处理 | 少提、少发和少收通过数量差异及原因记录，不额外创建补提或补发流程 |
| 审计追踪 | 关键动作产生履约批次或操作日志，保证过程可追溯 |

## 八、成本、费用与对账

| 成本区域 | 主要内容 |
|---|---|
| 采购侧 | 采购成本、产品包装、采购运费、入库费和库内加工费 |
| 物流侧 | 提货费、出库费、物流加工费、头程物流费、清关税费和其他头程费用 |
| 库存侧 | 按收货批次和发货批次沉淀库存成本、到岸成本、货值和仓租 |
| 分摊方式 | 按数量、重量、体积或金额，按业务场景选择 |
| 对账能力 | 导入实际账单，与预估费用对比，并保留负责人、附件和备注 |
| SKU 单位头程成本 | 按发货单 SKU 明细查询已有的实际头程分摊结果，不在查询页重复计算 |

## 九、跨模块业务链路

### 9.1 计划到采购

```text
需求预测
  ↓ 确认需求
备货计划
  ↓ 形成采购方案
采购计划
  ↓ 按供应商生成
采购单
  ↓ 收货形成供应商库存
供应商库存
```

### 9.2 采购到物流

```text
采购单收货 / 供应商库存可用
  ↓ 制定物流安排
发货计划
  ↓ 选择计划并提交
发货单
  ↓ 提货、加工、发货、收货
平台仓 / 海外仓库存
```

### 9.3 关键关联对象

| 上游对象 | 下游对象 | 主要关系 |
|---|---|---|
| 需求预测 | 备货计划 | 预测确认后生成备货安排 |
| 备货计划 | 采购计划 | 将需求缺口转为采购方案 |
| 采购计划 | 采购单 | 按供应商生成采购执行单 |
| 采购计划 | 发货计划 | 采购完成后安排物流 |
| 发货计划 | 发货单 | 以发货计划号关联和锁定履约计划 |
| 采购单 | 供应商库存 | 收货形成供应商库存和收货批次 |
| 发货单 | 平台仓/海外仓库存 | 收货形成目的仓库存和入库批次 |
| 发货单 | 成本与对账 | 物流履约结果进入费用分摊和 SKU 成本 |

| 成本管理 | 物流费用、头程成本和库存货值的基础记录与分摊 |

### 10.2 后续规划方向

| 规划方向 | 主要内容 |
|---|---|
| 主数据协同 | SKU 编码自动生成，以及中台与易仓/领星的主数据同步 |
| 辅料包材 | 完整的采购、库存和成本闭环 |
| 报价管理 | 更完整的供应商报价、价格趋势和报价附件审批 |
| 统计报表 | SKU 维度的备货、采购汇总与更丰富的库存报表 |
| 外部系统协同 | 更深的亚马逊、领星、易仓货件、物流和收货接口协同 |
| 异常履约 | 组合品拆分后子 SKU 独立发货、质检、不良品和退货处理 |
| 仓储协同 | 供应商 VMI、仓租精细化计算和导出工作台 |

### 10.3 仍需业务确认的事项

| 待确认主题 | 需要确认的内容 |
|---|---|

| 发货单异常 | 撤销、截单、少收和异常终止后的库存及 ERP 回滚规则 |
