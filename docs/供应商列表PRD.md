# 供应商列表 PRD

| 项目 | 内容 |
| --- | --- |
| 版本 | V1.0（草稿） |
| 日期 | 2026-10-07 |
| 模块 | 供应链 → 供应商管理 → 供应商列表 |

## 1. 需求背景与目标

供应商基础资料、联系人与结算信息需要在同一入口维护，采购人员需要快速定位可合作的供应商，并查看其结算、开票和变更记录。

目标：提供可查询、可新增、可编辑、可追溯的供应商资料管理页面。

## 2. 需求效益

- **采购效率**：按编码、名称、采购员及结算条件快速定位供应商。
- **协作清晰**：通过跟进采购员、合作状态和创建/更新时间明确资料责任与当前状态。
- **财务协同**：统一维护结算方式、支付方式和开票类型，减少采购与财务间的重复确认。
- **可追溯性**：保存操作日志，便于查询资料变更记录。

## 3. 适用范围与角色

| 角色 | 使用方式 |
| --- | --- |
| 采购员 | 查询、新增和编辑供应商资料；维护跟进采购员、联系及结算信息。 |
| 供应链管理员 | 查看全部供应商资料和操作日志。 |

本次包含供应商查询、列表、新增、编辑和日志；不包含审批、导入导出和批量删除。

## 4. 功能需求

| 功能 | 说明 |
| --- | --- |
| 查询 | 支持供应商编码多值精确匹配、供应商名称模糊查询，以及跟进采购员、结算方式、支付方式单选筛选。 |
| 列表 | 字段依次为：供应商名称、供应商编码、合作状态、跟进采购员、结算方式、支付方式、开票类型、创建人、创建时间、更新人、更新时间、操作。 |
| 复制 | 供应商名称、供应商编码右侧提供复制图标，复制成功后提示“已复制”。 |
| 新增/编辑 | 使用同一弹窗维护公司基本信息、联系方式、发货地址、退货地址、财务结算、证明资料与备注；右侧导航可跳转到对应区块。 |
| 日志 | 展示操作类型、日志内容、操作人和操作时间，支持分页。 |

列表不显示勾选框，不提供批量删除按钮。查询组件按 DOM 顺序横向紧凑排列，组件间距为 8px。

## 5. 核心功能逻辑

### 5.1 公司与状态

- 供应商编码由系统按现有最大序号自动生成，新增时只读。
- 供应商名称、信用代码、注册资金、注册日期、注册地址、可无理由退货、可退货周期、跟进采购员、合作状态为必填。
- 合作状态枚举：`合作中`、`禁用`；新增默认 `合作中`，在列表中展示，但不作为查询项。
- 供应商名称不可重复。

### 5.2 联系人与地址

- 联系人、手机号码、联系电话、微信号、电子邮箱均为选填；不维护 QQ 号码。
- 联系人、发货地址、退货地址均支持多条记录，并各自允许设置一条默认记录。
- 重复行使用垃圾桶图标删除。

### 5.3 财务结算与开票

| 字段 | 规则 |
| --- | --- |
| 结算币种 | 必填，当前枚举：RMB、USD、EUR。 |
| 结算方式 | 必填，支持月结 30/90/150/180 天、款到发货及两种预款结算方式。 |
| 支付方式 | 必填，枚举：线上支付宝、线下银行卡、跨境宝。 |
| 开票类型 | 必填，枚举：否、增值税普通发票、增值税专用发票。 |
| 开票税点 | 选择增值税普通发票或增值税专用发票时显示；选填，百分比输入。 |
| 实收税点 | 仅选择增值税专用发票时显示；选填，百分比输入。 |

### 5.4 操作留痕

- 新增和保存编辑后，系统更新更新人、更新时间，并新增一条操作日志。
- 创建人、创建时间在新增后固定保存；列表展示最新更新信息。

## 6. 数据、权限与验收

### 数据与权限说明

- 当前页面为原型数据实现；实际系统需按登录用户写入创建人、更新人和操作人。
- 结算、支付、开票类型及税点属于财务相关资料，应保留编辑日志。
- 供应商数据范围及“禁用”状态下是否允许在其他采购业务中被选择，需由业务方确认。

### 验收标准

1. 查询可按上述五类条件筛选，重置后恢复默认状态。
2. 列表字段、顺序和名称与本 PRD 一致，无勾选框和批量删除按钮。
3. 新增时自动生成供应商编码，必填项未填写时不可保存，重复名称不可保存。
4. 开票类型为“否”时不显示税点；普通发票显示开票税点；专用发票同时显示两类税点。
5. 名称和编码复制图标可复制对应文本并给出成功反馈。
6. 保存后创建/更新信息和操作日志符合上述留痕规则。
