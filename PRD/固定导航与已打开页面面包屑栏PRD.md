# 固定导航与已打开页面面包屑栏 PRD

| 项目 | 内容 |
|---|---|
| 需求名称 | 供应链中台固定框架与已打开页面面包屑栏 |
| 需求模式 | 轻量 |
| 文档版本 | 草稿 v1.0 |
| 适用范围 | 当前中台原型的供应链中台页面 |
| 需求目标 | 固定顶部导航和左侧菜单；在主内容区顶部保留多个已打开页面，支持切换、关闭及横向浏览。 |

## 1. 需求背景

当前中台原型的业务页面以独立页面形式打开。用户从左侧菜单跳转后，上一个页面会被替换，无法同时保留并切换已打开的采购计划、发货计划等页面；页面顶部也缺少统一、持续存在的页面导航区域。

需要将供应链中台改造成固定框架：顶部全局导航和左侧菜单不因切换业务页面而重新加载；业务页面在主内容区打开；红框位置展示“已打开页面面包屑栏”。

> 说明：本需求的“面包屑”不是传统的层级路径（如“首页 / 计划管理 / 采购计划”），而是按打开顺序保留的页面项，交互形态接近可关闭页签。

## 2. 已确认需求

1. 顶部全局导航固定展示：工作台、财务中台、供应链中台、运营中台、产品资料、企业工单。
2. 左侧供应链菜单固定展示。
3. 主内容区顶部展示已打开页面的面包屑栏。
4. 用户先打开“采购计划”，再打开“发货计划”时，面包屑栏至少展示“采购计划”“发货计划”；当前页面为发货计划。
5. 用户可点击已打开页面项，切换至对应页面。
6. 用户可关闭指定已打开页面。
7. 已打开页面过多、超过面包屑栏可视宽度时，在栏的最右侧展示左箭头和右箭头，用于横向浏览隐藏页面项。
8. 切换已打开页面时，已打开页面不能被销毁或重新初始化，应保留其当前使用状态（如已填写筛选条件、当前页码、展开状态、已打开但未关闭的弹窗等）。

## 3. 页面结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 固定全局导航：工作台｜财务中台｜供应链中台｜运营中台｜产品资料｜企业工单 │
├──────────────┬──────────────────────────────────────────────────────┤
│              │ 已打开页面面包屑栏                             [‹][›] │
│ 固定左侧菜单 ├──────────────────────────────────────────────────────┤
│              │                                                      │
│              │                  当前业务页面内容区                  │
│              │                                                      │
└──────────────┴──────────────────────────────────────────────────────┘
```

### 3.1 固定区域

| 区域 | 规则 |
|---|---|
| 顶部全局导航 | 始终固定在页面最顶部；切换采购计划、发货计划等业务页面时不得重新渲染或闪烁。当前所属中台（本需求为“供应链中台”）高亮。 |
| 左侧菜单 | 始终固定在全局导航下方；当前激活页面对应菜单高亮。 |
| 主内容区 | 位于左侧菜单右侧；从上到下由“已打开页面面包屑栏”和“当前页面内容”组成。 |

### 3.2 已打开页面面包屑栏

| 项目 | 规则 |
|---|---|
| 展示内容 | 展示当前会话内已经打开、但尚未关闭的业务页面名称，例如“采购计划”“发货计划”。 |
| 打开新页面 | 从左侧菜单点击页面时：若页面尚未打开，则在面包屑栏末尾新增；若已打开，则直接激活已有项，不重复新增。 |
| 当前项 | 当前页面项使用蓝色文字/下划线或等效高亮样式；左侧菜单同步高亮。 |
| 切换页面 | 点击非当前项后，切换至该项对应的缓存页面；不得丢失该页面的用户操作状态。 |
| 关闭页面 | 页面项右侧提供关闭按钮 `×`；关闭后从栏内移除其页面项和对应缓存实例。若关闭的是当前项，默认切换至其左侧最近一项；不存在左侧项时切换至右侧最近一项。 |
| 溢出浏览 | 页面项横向单行排列，不换行；可视范围不足时隐藏超出部分。左右箭头固定放在面包屑栏最右侧，点击后横向滚动页面项列表。 |
| 箭头状态 | 没有溢出时，左右箭头禁用或隐藏；已在最左端时左箭头禁用，已在最右端时右箭头禁用。 |
| 新增项定位 | 新打开或切换至被隐藏项时，系统自动滚动至该当前项可见。 |

### 3.3 示例

1. 初始进入“采购计划”：栏内显示 `采购计划 ×`，采购计划为当前项。
2. 点击左侧“发货计划”：栏内显示 `采购计划 ×  发货计划 ×`，发货计划高亮。
3. 点击“采购计划”：切回采购计划，采购计划原筛选状态保留。
4. 点击“发货计划”的 `×`：移除发货计划并回到采购计划。
5. 已打开页面过多：点击最右侧 `›` 向右查看被遮挡的页面；点击 `‹` 向左返回。

## 4. 功能需求

| 功能 | 入口 | 系统行为 | 验收关键点 |
|---|---|---|---|
| 打开页面 | 左侧菜单或页面内关联跳转 | 新页面加入已打开页面栏；已存在页面只激活 | 不出现同名重复项 |
| 切换页面 | 点击已打开页面项 | 显示对应页面缓存内容 | 页面状态保留 |
| 关闭页面 | 点击页面项的 `×` | 移除页面项及缓存内容，按规则切至相邻页面 | 当前项与非当前项均可正确关闭 |
| 横向浏览 | 面包屑栏右侧 `‹` / `›` | 平滑或步进滚动页面项区域 | 箭头固定在最右，状态正确 |
| 菜单联动 | 页面打开、切换、关闭后 | 左侧菜单仅高亮当前页面 | 不保留多个菜单高亮 |
| 地址同步 | 页面打开或切换后 | 推荐同步当前页面路由/hash，便于刷新或复制当前页面地址 | 刷新后至少能恢复当前页面 |

## 5. 实现约束（交给开发 / AI 的关键说明）

1. **必须存在唯一的系统壳层（Shell）**：顶部全局导航、左侧菜单、面包屑栏仅渲染一次，不能在采购计划、发货计划等每个业务页面中各渲染一套。
2. 业务页面只能作为 Shell 下方“内容区”的子页面加载；切换页面时应缓存实例。技术可选路由缓存（如 KeepAlive）、隐藏/显示多个内容容器或 iframe 缓存，但必须实现页面状态保留，且不能出现重复顶部导航和左侧菜单。
3. 当前项目存在直接访问 `pages/采购计划/index.html` 之类独立页面的使用方式。实施时必须二选一：
   - 统一由根入口加载所有业务页面；直接访问子页面时自动重定向到根入口及对应路由；或
   - 每个子页面检测独立打开时主动挂载同一套 Shell。

   不允许只在根入口增加面包屑栏、而让直接打开业务子页面的用户看不到改动。
4. 页面内现有的 `data-page-nav`、关联单据跳转等导航入口，均须接入同一个“打开/激活页面”方法，不能继续使用整页 `location.href` 替换。
5. 本期仅覆盖供应链中台菜单已存在页面：需求预测、备货计划、采购计划、发货计划、采购单、发货单、头程费用、供应商库存、加工单。其他中台顶部导航暂不要求实现真实跳转。

## 6. 数据、权限与日志影响

- 不新增业务数据字段，不影响采购、发货、库存等业务数据。
- 沿用原页面菜单和数据权限；面包屑栏不赋予额外页面访问权限。
- 不要求记录打开、切换、关闭页面的操作日志。
- 不涉及金额、库存口径、财务、税务或审计规则变更。

## 7. 异常与边界场景

| 场景 | 处理规则 |
|---|---|
| 重复点击同一菜单 | 不新增重复页面项，只切换至已有页面项。 |
| 关闭当前项 | 按“左侧优先、右侧兜底”规则切换相邻项。 |
| 关闭非当前项 | 当前页面不切换，仅移除目标页面。 |
| 页面加载失败 | 当前项显示加载失败状态，并提供“重新加载”入口；其他已打开页面可正常切换。 |
| 页面名称过长 | 单个页面项超出最大宽度时省略号展示，悬浮显示全称。 |
| 浏览器刷新 | 至少恢复当前路由对应的页面；是否恢复全部已打开页面见待确认问题。 |
| 直接访问业务子页面 | 必须按“实现约束”第 3 条处理，不能绕开固定 Shell。 |

## 8. 验收标准

1. 打开采购计划后，全局顶部导航、左侧菜单、面包屑栏均可见；面包屑栏显示“采购计划”。
2. 在采购计划已打开的情况下打开发货计划，顶部固定导航和左侧菜单不消失、不重复出现；面包屑栏显示“采购计划、发货计划”，发货计划高亮。
3. 点击“采购计划”面包屑后能返回采购计划，且此前输入的筛选条件、分页等页面状态仍存在。
4. 再次点击已打开的“采购计划”菜单时，面包屑栏不新增第二个“采购计划”。
5. 点击任一非最后页面的关闭按钮后，仅关闭该页面；其余页面和状态保持正常。
6. 关闭当前页面时，自动显示相邻页面且左侧菜单高亮同步更新。
7. 将页面项数量增加到超出可视宽度后，右侧 `‹` / `›` 位于栏最右侧，能够查看所有被遮挡的页面项；滚动到边界时对应箭头不可用。
8. 直接从业务子页面地址进入时，仍能进入带固定顶部、左侧菜单和面包屑栏的页面框架。
9. 不出现重复的顶部导航、重复左侧菜单或两层内容滚动区域。

## 9. 待确认问题

| 问题 | 建议默认方案 | 影响 |
|---|---|---|
| 最后一个已打开页面是否允许关闭 | 建议不展示最后一项的关闭按钮，确保主内容区始终有页面。 | 关闭交互与空状态 |
| 浏览器刷新后是否恢复全部已打开页面 | 建议仅恢复当前页面；若需恢复全部页面，可将已打开页面列表持久化到浏览器存储。 | 刷新体验、实现复杂度 |
| 顶部其他中台是否需要各自独立的页签集合 | 本 PRD 仅处理供应链中台；切换其他中台的行为待单独定义。 | 全局导航后续扩展 |
