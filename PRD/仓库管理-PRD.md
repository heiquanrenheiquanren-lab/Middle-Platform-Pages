# 仓库管理 PRD

## 一、文档信息

| 项目 | 内容 |
|---|---|
| 需求名称 | 仓库管理 |
| 需求模式 | 轻量需求 |
| PRD 版本 | 草稿版 |
| 所属模块 | 工作台 → 业务组织 → 仓库管理 |

## 二、需求背景

当前中台尚未统一维护仓库基础数据，系统内缺少完整、可查询的仓库主数据。后续在采购单、发货单等业务单据中需要引用仓库时，无法直接选择或获取标准仓库信息，容易产生手工补录、数据不一致和关联缺失的问题。

因此新增仓库管理页面，作为仓库基础信息的统一维护入口。

## 三、需求目标与效益

### 3.1 需求目标

1. 建立仓库主数据的查询、创建、编辑、删除和日志追溯能力。
2. 统一维护仓库类型、关联对象、所在地、负责人和地址等基础信息。
3. 为采购单、发货单及后续涉及仓库的业务场景提供标准仓库数据。

### 3.2 需求效益

- **补齐主数据**：中台具备独立的仓库数据维护能力，不再依赖业务方临时提供或人工补录。
- **数据统一**：仓库信息集中维护，减少不同单据和页面引用不一致的问题。
- **支撑下游业务**：采购单、发货单等后续单据可基于统一仓库数据进行选择和关联。
- **可追溯**：仓库新增、编辑、类型调整、删除等操作均可查询日志。

## 四、功能范围

### 4.1 页面入口

入口位于：工作台 → 业务组织 → 仓库管理。

### 4.2 查询功能

| 查询项 | 控件 | 规则 |
|---|---|---|
| 仓库名称 | 多选下拉 | 支持仓库名称枚举模糊搜索；多选按 OR 匹配 |
| 仓库类型 | 下拉单选 | 默认全部 |
| 启用状态 | 下拉单选 | 启用、停用；默认全部 |
| 所在国家 | 下拉单选 | 默认全部 |
| 关联平台 | 下拉单选 | 默认全部，仅用于筛选平台仓关联平台 |

### 4.3 列表功能

列表展示以下字段：

1. 序号
2. 仓库名称、仓库编码
3. 所在国家
4. 仓库类型
5. 关联平台
6. 仓库状态
7. 仓库地址
8. 仓库负责人
9. 操作

列表操作包括：编辑、删除、日志。

### 4.4 新增与编辑仓库

| 字段 | 规则 |
|---|---|
| 仓库编码 | 系统自动生成，只读 |
| 仓库名称 | 必填 |
| 所在国家 | 必填 |
| 仓库类型 | 必填 |
| 关联对象 | 根据仓库类型动态展示；展示时必填 |
| 站点 | 平台仓选择关联平台后，展示该平台对应站点枚举 |
| 仓库负责人 | 非必填文本输入 |
| 联系电话 | 非必填 |
| 仓库地址 | 国家、省/州、城市、区/县、详细地址分段维护 |
| 仓库功能、邮编、官网链接 | 非必填 |
| 仓库状态 | 启用、停用；新增默认启用 |

官网链接仅在新增/编辑弹窗维护，不在列表展示。

### 4.5 仓库类型联动

| 仓库类型 | 必填关联字段 |
|---|---|
| 自营仓 | 无 |
| 供应商仓 | 关联供应商 |
| 物流商仓 | 关联供应商 |
| 物流中转仓 | 关联头程服务商 |
| 海外仓 | 关联海外仓服务商 |
| 平台仓 | 关联平台 |

平台仓选择关联平台后，站点枚举随平台联动；非平台仓不启用站点选择。

### 4.6 补充枚举

| 字段 | 枚举值 |
|---|---|
| 海外仓箱唛尺寸 | 100*100、100*150 |
| 条码类型 | 条形码、二维码 |
| 条码尺寸 | 70*30、70*50、50*30 |

### 4.7 删除与日志

- 删除仓库前需二次确认。
- 操作日志复用发货单日志弹窗结构，展示操作类型、日志内容、操作人、操作时间。
- 新增、编辑、仓库类型调整、删除均需记录日志。

## 五、数据使用规则

1. 仓库管理页面维护的是仓库主数据。
2. 后续采购单、发货单等需要选择或引用仓库时，应使用本页面维护的仓库数据及基础信息。
3. 本期不展开采购单、发货单的具体字段改造和校验逻辑；下游单据接入时沿用各自业务规则。
4. 页面查询、查看和维护权限沿用中台现有账号权限体系。

## 六、验收标准

1. 用户可从工作台「业务组织 → 仓库管理」进入页面。
2. 支持按仓库名称、仓库类型、启用状态、所在国家、关联平台查询。
3. 用户可新增、编辑、删除仓库；新增后列表即时可见。
4. 仓库编码自动生成；仓库名称、所在国家、仓库类型为必填。
5. 不同仓库类型正确展示对应关联字段，并对关联字段执行必填校验。
6. 平台仓选择关联平台后，站点仅展示对应平台的站点枚举。
7. 列表不展示官网链接，弹窗仍可维护官网链接。
8. 新增、编辑、类型调整和删除操作均可在日志中追溯。

## 七、待确认问题

| 问题 | 影响 |
|---|---|
| 仓库编码正式规则是否由后端统一编码服务生成？ | 影响编码生成方式 |
| 停用仓库是否允许在采购单、发货单中继续被选择？ | 影响下游单据校验规则 |
| 仓库数据是否需要按组织、团队或国家进行数据权限隔离？ | 影响查询范围和操作权限 |
