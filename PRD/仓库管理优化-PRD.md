# 仓库管理页面优化 PRD

> **版本**：V1.1｜**日期**：2026-11-19｜**原型**：`pages/workbench/index.html#warehouseSku`

---

## 一、改动总览

1. **移除 Tab 栏**：去掉「仓库SKU管理」Tab 及顶部 Tab 栏，进入「基础配置 → 仓库管理」直接展示仓库管理列表。
2. **页面与弹窗视觉对齐 UI 规范**：
   - 页面采用中台 `10px` 纵向骨架（查询卡片 → `10px` → 32px 操作行 → `10px` → 列表卡片），列表去竖线。
   - **新增/编辑仓库弹窗**改为简约白卡风格：弹窗固定居中（`820×620px`、`10px` 圆角），内容区 `#F7F9FC` 灰底 + `.ui-form-card` 白色细边卡片，双列布局，标签左置右对齐、控件高 `32px`。
   - 删除确认与操作日志弹窗同步对齐 `.ui-dialog--confirm` / `.ui-dialog--log` 规范。
3. **字段调整**：
   - 列表「仓库」列更名为「**仓库名称**」；其后新增「**简称**」列（空值显示 `—`）。
   - 新增/编辑弹窗在「仓库名称」后新增「**简称**」输入框（选填）。
   - 弹窗「**所在国家**」改为**必填**（红色 `*` + 标红校验提示），并与地址栏国家下拉联动同步。
4. **国家枚举标准化**：查询区、列表「所在国家」列、弹窗「所在国家」及地址国家下拉统一接入 40 国标准枚举，格式为 **`国家名称（二位代码）`**（如 `中国（CN）`、`波兰（PL）`）。

---

## 二、页面与列表调整

### 2.1 查询区
- **保留筛选项**：仓库名称（多选模糊搜索）、仓库类型（单选）、启用状态（单选）、关联平台（单选）。
- **所在国家（调整）**：下拉枚举扩展为第 4 章 40 个国家，展示格式为 `国家名称（二位代码）`，下拉面板最大高度 `280px` 支持滚动。

### 2.2 列表字段（共 10 列）
`序号` ｜ `仓库名称`（主行名称 + 副行编码）｜ **`简称`**（新增，空值 `—`）｜ **`所在国家`**（`国家名称（二位代码）`）｜ `仓库类型` ｜ `关联平台` ｜ `仓库状态` ｜ `仓库地址` ｜ `仓库负责人` ｜ `操作`（编辑 / 删除 / 日志，吸右固定）

---

## 三、新增 / 编辑仓库弹窗

### 3.1 核心字段变更与校验

| 字段 | 必填 | 位置/类型 | 规则说明 |
|---|---|---|---|
| 仓库名称 | 是 | 文本输入 | 必填校验，空值提示 `请输入仓库名称` |
| **简称** | 否 | 文本输入 | **新增**，位于「仓库名称」后，支持新建录入与编辑回显 |
| **所在国家** | **是** | 下拉单选 | **改为必填**，使用 40 国枚举（`国家名称（二位代码）`）；未选提示 `请选择所在国家`；选择后自动同步下方地址国家 |
| 仓库类型 | 是 | 下拉单选 | 自营仓（无关联对象）、供应商仓（关联供应商）、物流中转仓（关联头程服务商）、海外仓（关联海外仓服务商）、平台仓（关联平台 → 联动站点） |
| 仓库地址 | 否 | 五段组合 | 国家（40 国枚举，与「所在国家」双向联动）+ 省/州 + 城市 + 区/县 + 详细地址 |
| 其余字段 | 按原规则 | — | 仓库编码（只读自动生成）、负责人、站点、箱唛尺寸、条码类型/尺寸、联系电话、仓库功能、邮编、官网链接（仅弹窗维护）、仓库状态（默认启用，必填） |

> 点击「确定」校验失败时，对应输入框/下拉框边框标红（`#F56C6C`）并在底部展示错误文案；重新输入或选择后自动清除标红。

## 五、验收标准

1. **无 Tab 栏**：进入仓库管理页顶部无 Tab 栏，直接显示仓库列表；三段卡片左右对齐、间距 `10px`。
2. **字段完整**：列表首列为「仓库名称」，其后为「简称」（空值 `—`）与「所在国家」；新建/编辑弹窗支持录入与回显「简称」。
3. **国家必填**：弹窗「所在国家」带红色 `*`，未选提交时标红并提示 `请选择所在国家`，选择后自动联动地址国家下拉。
4. **枚举统一**：查询下拉、列表列、弹窗国家下拉均完整包含 40 个国家且按 `国家名称（二位代码）` 展示，筛选准确。
