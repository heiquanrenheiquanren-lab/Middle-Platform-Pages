# 发货单优化 V2.2 PRD

> **关联原型**：`pages/shipment-orders/index.html`、`pages/shipment-orders/app.js`、`pages/shipment-orders/styles.css`  
> **文档版本**：V2.2  
> **更新日期**：2026-11-17

---

## 1. 概述

### 1.1 迭代背景
为进一步精简中台发货单的履约状态链路、统一列表视觉规范（对齐采购单列表标准），并规范新建发货单时的仓库、运输方式与物流渠道枚举，本次对**发货单**页面进行 V2.2 版本专项优化。

### 1.2 本期变更范围
- **状态与操作精简**：移除「待加工」状态页签及相关流转；移除顶部与行内「物流加工」按钮；操作列移除「查看」按钮。
- **列表与二级明细优化**：主表表头改白、单号列左侧增加一键展开/收起按钮、移除「易仓」标识、状态标识对齐采购单样式、二级明细铺满宽度并对齐采购单行高与「品名」占位图展示、修复草稿态二级明细无数据问题。
- **新建发货单弹窗优化**：弹窗居中显示、规范发货仓/目的仓/发货方式/运输方式/物流渠道的枚举与默认值、发货仓/目的仓地址信息置灰不可编辑。

## 2. 状态与操作栏变更

### 2.1 状态页签调整
- **变更前**：`全部`、`草稿`、`待提货`、`待加工`、`待发货`、`待收货`、`部分收货`、`已完成`、`已作废`、`已取消`
- **变更后**：移除 `待加工`，保留以下 9 个页签：
  `全部`、`草稿`、`待提货`、`待发货`、`待收货`、`部分收货`、`已完成`、`已作废`、`已取消`
- **流转规则调整**：提货完成后不再进入「待加工」，直接流转为 `待发货`。

### 2.2 顶部操作栏调整
- **移除**：`物流加工` 批量操作按钮。
- **保留**：`＋ 新建发货单`、`导入物流费用`、`导入轨迹信息`、`其他头程费用分摊`、`导出`（发货单信息 / 发货 SKU 明细）。

### 2.3 列表「操作」列调整
- **移除**：所有状态行中的 `查看` 按钮（用户可通过点击「中台发货单」单号打开详情弹窗）以及 `待加工` 分支下的 `物流加工` 按钮。
- **各状态操作按钮明细**：

| 单据状态 | 操作列按钮 |
| --- | --- |
| 草稿 | 编辑、提交、作废、日志 |
| 待提货 | 提货、取消发货、日志 |
| 待发货 | 发货、数量调整、日志 |
| 待收货 | 收货、数量调整、日志 |
| 部分收货 | 收货、数量调整、手动完成、日志 |
| 已完成 | 日志 |
| 已作废 | 编辑、日志 |
| 已取消 | 日志 |

## 3. 发货单列表与二级明细优化

### 3.1 主表表头与一键展开
1. **表头背景色**：主表一级表头行（勾选列、展开列、`单号`、`仓库＆渠道`、`数量汇总`、`差异数量`、`发货时间`、`入库信息`、`创建&备注`、`头程费用`、`操作`）统一改为纯白色 `#FFFFFF`。
2. **一键展开/收起按钮**：
   - 位置：位于勾选列右侧、`单号`列左侧的展开列表头中。
   - 样式与交互：复用 `document-list.css` `.expand-btn` 箭头样式（与采购单一致）。点击可一键展开或收起当前筛选结果下的全部发货单二级明细；当所有行均展开时箭头旋转为展开态（`.open`）。

### 3.2 单号列与状态标识优化
1. **移除「易仓」标识**：列表 `ERP发货单` 行以及详情弹窗中，不再显示 `易仓` 标签。
2. **状态标识位置与样式优化（对齐采购单）**：
   - 位置：从 `发货方式` 行移至 `中台发货单` 单号右侧展示。
   - 样式：采用与采购单 `.status-tag` 一致的风格（`3px` 圆角、`padding: 3px 6px`、`11px` 字号、`font-weight: 500`、无边框与圆点，浅底深字）：
     - `已完成`：浅绿底 `#f0f9eb` / 绿字 `#52a31b`
     - `待发货`：浅蓝底 `#ecf5ff` / 蓝字 `#1677ff`
     - `待提货`、`待收货`、`部分收货`：浅橙底 `#fff7e6` / 橙字 `#d48806`
     - `已作废`、`已取消`：浅红底 `#fef0f0` / 红字 `#f56c6c`
     - `草稿`：浅灰底 `#f4f4f5` / 灰字 `#909399`

### 3.3 二级 SKU 明细列表优化
1. **铺满容器宽度**：二级列表设置 `width: 100%; min-width: 1650px`，各列采用 `min-width` 自适应分配宽度，在宽屏下自动铺满展开区域，消除右侧空白。
2. **表头与行高对齐采购单**：
   - 表头背景保持浅灰 `#f5f7fa`，高度 `38px`。
   - 数据行高度统一为 `62px`（`padding: 7px 0`）。
3. **「品名」列与占位图**：
   - 原 `产品信息` 列标题改名为 **`品名`**。
   - 品名前方缩略图尺寸调整为 `30px × 30px`（`border: 1px solid #e4e9f2; border-radius: 4px; background: #fafafa`），统一使用系统占位图片（`placeholderProductImage`）。
4. **草稿态二级明细补全**：所有「草稿」状态的发货单均应展示对应的 `items` SKU 明细及汇总数量，避免展开后显示 `No Data`。

## 4. 新建/编辑发货单弹窗优化

### 4.1 弹窗定位
- 弹窗使用垂直水平居中显示（`align-center` + `margin: auto`），不再置顶贴边。

### 4.2 表单字段枚举、默认值与禁用规则

| 字段名称 | 控件类型 | 选项枚举 | 默认值 | 编辑限制 |
| --- | --- | --- | --- | --- |
| **发货仓** | 下拉单选 | `跨跃猫物流仓`（有且仅有此选项） | `跨跃猫物流仓` | 必选 |
| **目的仓** | 下拉单选 | 常用仓排序置顶：<br>1. `跨跃猫美西一件代发仓 美西仓`<br>2. `跨跃猫美西一件代发仓 多伦多3仓`<br>3. `跨跃猫美西一件代发仓 纽约仓`<br>其余仓库顺延排列 | 不默认选中 | 必选 |
| **发货方式** | 下拉单选 | `海外仓发货` | `海外仓发货` | 必选 |
| **运输方式** | 下拉单选 | `海派（6000）`、`海卡（6000）`、`空派（5000）`、`快递（8000）`、`铁运（5000）`、`卡航（5000）`、`一件代发（8000）` | `海卡（6000）` | 必选 |
| **物流渠道** | 下拉单选 | `普船卡派`、`普船快递派`、`空运`、`快船快递派`、`快船卡派`、`铁路`、`自提卡派` | 不默认选中 | 必选 |
| **发货仓信息** | 表单区块 | 联系人、联系电话、国家、省/州、城市、区/县、详细地址、邮编 | 随发货仓自动带出 | **全部置灰不可编辑**（`disabled`） |
| **目的仓信息** | 表单区块 | 联系人、联系电话、国家、省/州、城市、区/县、详细地址、邮编 | 随目的仓自动带出 | **全部置灰不可编辑**（`disabled`） |

### 4.3 「新增 SKU」弹窗优化
1. **UI 风格与布局**：采用与新建发货单一致的居中弹窗、`minimal-card` 分区卡片与底部已选 SKU 统计；查询条件支持 `发货计划`、`SKU`、`目的仓`、`平台`、`店铺`、`团队`。
2. **目的仓默认筛选**：打开弹窗及点击重置时，默认勾选新建发货单中已选择的「目的仓」。
3. **支持亚马逊发货计划与 SKU**：移除「同一发货单仅支持同一目的仓的货物合并发货；亚马逊相关发货单由领星生成，不在中台手动创建」提示语，取消 `平台`、`店铺` 下拉中对亚马逊选项的禁用限制及候选列表的亚马逊过滤。
4. **列表字段与顺序**：依次为
   `SKU`、`发货计划`、`目的仓`、`海外仓 SKU`、`领星SKU`、`团队`、`计划发货量`（从发货计划带出）、`发货量`（必填）、`提货仓`（从发货计划带出）、`备注`、`平台`、`店铺`、`运营负责人`、`箱数`（填写发货量之后按装箱数实时带出）。

## 5. 验收标准

1. 发货单列表页不再出现「待加工」页签、顶部/行内「物流加工」按钮、「查看」按钮以及列表「易仓」标识。
2. 主表表头为纯白色，单号列左侧支持一键展开/收起全部明细，状态标识样式与采购单一致。
3. 展开任意发货单（含草稿态），二级列表横向铺满容器、表头为 `#f5f7fa`、行高为 `62px`、「品名」列使用 `30×30` 占位图且数据正常展示。
4. 点击「＋ 新建发货单」，弹窗在视口内上下左右居中；发货仓仅可选且默认选中「跨跃猫物流仓」；目的仓前 3 项为指定常用仓且不默认选中；发货方式默认「海外仓发货」；运输方式默认「海卡（6000）」且枚举完整；物流渠道为指定 7 项单选枚举；发货仓信息与目的仓信息全部置灰不可编辑。
