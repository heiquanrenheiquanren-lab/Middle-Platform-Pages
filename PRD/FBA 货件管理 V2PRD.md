> **关联原型**：`pages/fba-shipment/index.html`、`pages/fba-shipment/styles.css`、`pages/fba-shipment/app.js`

## 1. 概述

### 1.1 需求背景与页面定位
亚马逊头程履约链路升级后，**「关联发货计划」入口统一收拢至「发货计划 V2」**，中台发货单则由发货计划/发货流程统一流转生成；本页面（**FBA 货件**）聚焦 **领星 FBA 货件台账查询、计划关联与发货单状态跟踪、收发差异核对与按配置导出**：

```mermaid
flowchart LR
  P["发货计划 V2\n新建计划并关联 FBA 货件"] --> O["领星 / 亚马逊后台\n同步 FBA 货件主表与 SKU 明细"]
  O --> D["发货单模块\n流转生成并执行出库发货"]
  O --> V["FBA 货件页（本页）\n多维度查询 + 中台发货单状态跟踪 + 申发/收发/申收差异核对"]
  D --> V
  V --> E["全局导出中心\n按列配置导出 .xlsx 明细报表"]
```

### 1.2 产品目标与本期范围
- **纯查看、核对与导出台账定位**：移除原页面内「生成发货单」「关联发货计划」「取消关联」「同步领星货件」操作按钮及相关弹窗，同步去掉一、二级列表复选框列，列表更聚焦于信息检索与对账。
- **统一列表与交互规范**：主从折叠列表对齐「采购计划 V2」列表骨架、字体/字号/字重、列配置抽屉与底部汇总规范，并取消一、二级固定列。
- **查询项精细化升级**：`品名` 独立模糊查询、`领星货件状态` 支持多选、`发货单状态` 对齐发货单全状态、`差异状态` 支持多选（`有申发差异` / `有收发差异` / `有申收差异`），去掉 `完结状态` 与 `更新时间`。
- **发运与差异口径可视化**：在「中台发货单号」旁展示发货单状态标识；二级列表 `实际发货`、`申发差异`、`收发差异`、`申收差异` 表头均提供 `?` 即时悬浮提示说明，明确数值口径与异常差异高亮。
- **按列配置导出与跨页联动**：支持点击「中台发货单号」/「发货计划」跳转对应单据页，支持按当前查询结果与「列配置」勾选字段动态导出 `.xlsx` 文件。

> **说明**：已移除「完结状态」查询与「更新时间」查询。

### 3.2 查询交互与折叠规则
- **两行自适应折叠**：在 `1024px`、`1440px`、`2048px` 等主流视口下，前两行放不下的查询项自动收起并展示 `展开/收起` 按钮；`查询`、`重置` 按钮固定跟随可见行末尾且同排可见。
- **日期校验**：若同时填写了开始日期和结束日期且 `开始日期 > 结束日期`，阻止查询并弹出错误提示「开始日期不能晚于结束日期」。
- **快捷查询**：在 `单号组合`、`编码组合`、`品名` 输入框按 `Enter` 键直接触发查询；输入框支持一键清空，多选下拉支持 `×` 一键清空。
- **重置**：点击 `重置` 清空所有筛选项、多选下拉与日期区间，口径下拉恢复默认（单号默认为 `货件单号`、编码默认为 `SKU`、日期默认为 `创建时间`），重置页码至第 1 页并重新渲染列表。

## 6. 导出功能规范

### 6.1 导出触发与基础规则
- **入口与前置校验**：点击顶部操作栏 `导出` 按钮，校验当前筛选命中的货件数量 `> 0`；若当前筛选结果为空，阻断触发并提示「当前筛选条件下暂无可导出的数据」。
- **导出范围与粒度**：
  - 按**当前查询条件命中的全量数据**导出（不受当前分页大小或页码切割限制）。
  - 采用 **「FBA 货件 × SKU 明细」展平结构**：1 条 SKU 明细占 1 行，所属一级货件主信息在各明细行重复填充，便于透视汇总与财务/供应链对账。
- **文件格式与异步任务**：统一导出 **`.xlsx`** 格式，接入全站共享「导出中心」（`global-export.js`），创建类型为 `FBA货件导出` 的异步任务并携带当前筛选条件快照；用户可在页面右上角「导出中心」查看进度与下载文件（处理完成后保留 24 小时，过期需回到列表页重新发起）。

## 8. 验收标准与待研发确认问题

### 8.1 核心验收标准
1. **导航与列表结构**：侧栏菜单「FBA货件」位于「计划管理」分组内的 `采购计划` 与 `发货计划` 之间；顶部操作栏仅保留 `导出` 与 `列配置`；一、二级列表均无复选框列且无横向固定列，字号字重对齐采购计划 V2。
2. **查询功能**：10 组查询项完整可用，编码下拉不含「品名」，`品名` 独立模糊查询；`领星货件状态` 支持多选，`发货单状态` 枚举覆盖 `未生成发货单`、`已生成发货单` 及 7 种发货单具体状态，`差异状态` 支持多选（`有申发差异` / `有收发差异` / `有申收差异`）；无 `完结状态` 与 `更新时间` 查询，起止日期具备先后校验；支持两行折叠、回车查询与一键重置。
3. **字段展示与问号提示**：一级 `中台发货单号` 旁正确显示发货单状态徽标；二级 `实际发货` 在未生成发货单或未发货状态时显示 `—`；`实际发货`、`申发差异`、`收发差异`、`申收差异` 四个表头 `?` 悬停立即显示正确文案且不被表格裁切。
4. **列配置**：点击右侧「列配置」图标可抽屉式配置一、二级可见列与拖拽排序（无固定列限制），至少保留 1 列，保存后即时生效并跨刷新保留。
5. **导出功能**：点击 `导出` 校验筛选结果非空后创建 `FBA货件导出`（`.xlsx`）任务，按「货件 × SKU 明细」展平导出当前筛选命中的全部结果，且导出列严格受「列配置」勾选与排序控制（默认全选为 26 列），可在右上角「导出中心」下载。
