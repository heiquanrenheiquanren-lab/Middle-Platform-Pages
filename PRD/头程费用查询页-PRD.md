# 头程费用查询页 PRD

## 一、文档信息

| 项目 | 内容 |
|---|---|
| 需求名称 | 头程费用查询页（历史名称：SKU 单位头程成本） |
| 需求模式 | 轻量 |
| PRD 版本 | v0.3（补充发货单总费用构成提示） |
| 适用模块 | 头程费用查询、发货单、SKU 明细、费用分摊结果 |
| 需求目标 | 提供一个按发货单 SKU 明细查询头程费用分摊结果的统一入口，支持多维筛选、全量合计与导出，金额统一使用 CNY。 |

## 二、背景、目标与范围

### 2.1 背景

头程费用的分摊规则与分摊结果已由既有功能产生（物流费用导入、头程费用分摊），但缺少一个面向业务人员的查询展示页面，无法按发货单、SKU、目的仓、平台等维度快速检索分摊结果，也无法快速核对单位成本与差异。

### 2.2 目标

1. 提供一个查询页，按发货单 SKU 明细展示已有头程分摊结果。
2. 支持单号、SKU、仓、渠道、平台、店铺、团队、创建人、日期等多维筛选。
3. 底部展示全量查询结果的合计（发货单总费用、单位成本合计、差异合计），不受分页影响。
4. 支持导出全部查询结果。

### 2.3 本次范围

- 头程费用查询页：查询区、列表展示、整行合计、导出、刷新。
- 分摊规则、自动触发条件、分摊结果生成与查询页展示口径。
- 分摊结果的精度、单位成本、差异、合计的定义与校验。

### 2.4 非本次范围

- 头程费用录入页面的整体改造、费用导入方式和轨迹导入（沿用已有功能）；本次仅补充分摊触发与计算结果联动。
- 除「头程费用」外的其他费用类型查询。

### 2.5 需求效益

1. **降低取数成本，支撑多部门成本相关业务**：头程分摊结果被多个场景反复取用，本页提供统一、可筛选、可导出的查询入口，替代人工从账单和 Excel 中手工拼数：
   - **财务**：月度加权成本核算、成本类报表（存货成本、销售成本）取数；
   - **定价**：SKU 定价/调价时需要头程成本作为成本加成依据；
   - **物流与计划**：物流费用核算、渠道与服务商费用对比；
   - **其他**：SKU/店铺/团队毛利分析、选品与采购决策、物流供应商比价、海外仓入仓成本核算等。
   - 统一取数口径，减少口径不一致与数据返工。

2. **为分摊算法评估与优化提供数据基础**：本页按发货单完整呈现分摊结果（单位成本、发货单总费用、差异），用于：
   - 识别分摊异常：费用未分摊、差异过大、分摊比例异常等；
   - 评估现有分摊算法在不同发货单/SKU 上的合理性与准确性；
   - 沉淀历史分摊数据，为后续优化分摊算法（如按重量、体积、计费重等维度调整）提供数据依据。

3. **提升业务透明度**：业务、财务可直接查看每个发货单的分摊明细与差异，理解费用去向，减少对分摊结果的质疑与线下反复核对。

## 三、核心定义与数据口径

### 3.1 核心对象

| 对象 | 定义与关系 |
|---|---|
| 发货单 | 一张发货单包含多个 SKU 明细，是费用分摊的承载单据。 |
| SKU 明细 | 发货单下每个 SKU 一行，含实际发货数量、收货数量、单位头程成本。 |
| 发货单总费用 | 发货单总费用 = 头程物流费 + 清关税费 + 其他物流费用。 |
| 单位头程成本 | 单个 SKU 在该发货单内分摊到的头程成本（CNY），由自动分摊结果产生。 |

### 3.2 数据口径

| 字段 | 口径 |
|---|---|
| 实际发货数量 | 用于分摊计算的发货数量；以实际发货数量为准，不使用计划数量或收货数量。 |
| 头程物流费 | 发货单级物流费用，作为按计费重分摊的费用来源。 |
| 清关税费 | 头程费用组成之一；已归属具体 SKU 的税费直接计入对应 SKU。整票级税费的分摊方式待确认。 |
| 其他物流费用 | 港口维护费、清关费等其他费用，作为按计费重分摊的费用来源。 |
| 分摊单价 | 可分摊的物流及其他费用总额 ÷ 整票总计费重；用于计算各 SKU 分摊的物流及其他费用。 |
| SKU 单位头程成本（CNY） | 来自自动分摊功能的分摊结果，本页只展示不重新计算。 |
| 发货单总费用提示 | 在「发货单总费用」列表表头增加问号图标，悬停提示：发货单总费用 = 头程物流费 + 清关税费 + 其他物流费用。 |
| 差异 | 差异 = Σ（各 SKU 单位成本 × 实际发货数量）− 发货单总费用。按发货单维度计算，同一发货单下所有 SKU 明细行的差异值相同；0 表示费用分摊完整，负数表示有费用未分摊到 SKU。 |
| 实际发货数量为 0 | 该行单位成本显示「—」，不参与合计。 |
| 差异显示 | 差异为 0 显示灰色，非 0 显示红色。 |
| 发货单总费用合计 | 按发货单去重求和（避免同单多行重复累加）。 |
| 单位成本合计（CNY） | Σ（单位成本 × 实际发货数量），对全部查询结果求和。 |
| 差异合计（CNY） | 按发货单去重求和（同单多行差异值相同，仅累加一次）。 |
| 合计范围 | 全部合计均基于用户查询筛选后的**全部结果**计算，不受当前分页影响。 |

### 3.3 分摊计算规则

分摊以发货单为计算单元，按发货单下各 SKU 的计费重占比分摊物流费用。计算使用实际发货数量。

> 说明：本次按截图及中台字段表的既有口径统一，体积总重量中的“体积参数”为除数，不是乘数。用户补充描述中的“×体积参数”按此处修正为“÷体积参数”。

1. **SKU 实际总重量**

   ```text
   SKU实际总重量 = 单品毛重 × 该SKU的实际发货数量
   ```

   单品毛重、实际总重量的单位均为 kg。若同一 SKU 存在多种包装规格或单品毛重，应按不同规格分别计算后求和。

2. **SKU 体积总重量**

   ```text
   SKU体积总重量 = （长 × 宽 × 高 ÷ 体积参数）× 该SKU的实际发货数量
   ```

   长、宽、高的单位为 cm；体积参数根据物流方式配置，现有口径包括 5000、8000。若同一 SKU 存在多种包装规格，应按不同规格分别计算后求和。

3. **SKU 计费重**

   ```text
   SKU计费重 = MAX（SKU实际总重量，SKU体积总重量）
   ```

4. **整票总计费重**

   ```text
   整票总计费重 = Σ（发货单内各SKU计费重）
   ```

5. **物流及其他费用分摊**

   ```text
   分摊单价 = 可分摊的物流及其他费用总额 ÷ 整票总计费重
   SKU物流及其他费用 = 分摊单价 × SKU计费重
   ```

   其中，头程物流费、其他物流费用按计费重占比分摊。清关税费如果已在费用明细中归属到具体 SKU，则直接计入该 SKU；整票级清关税费的分摊方式见“待确认问题”。

6. **SKU 头程总成本与单位头程成本**

   ```text
   SKU头程总成本 = SKU物流及其他费用 + SKU直接归属税费
   SKU单位头程成本 = SKU头程总成本 ÷ SKU实际发货数量
   ```

   实际发货数量为 0 时，单位头程成本显示「—」，该 SKU 不参与单位成本合计。

### 3.4 精度规则

- 头程费用页面所有金额、单价、差异及相关计算结果统一最多展示 6 位小数，尤其是分摊单价。
- 分摊计算及中间结果使用高于 6 位小数的精度，不在中间步骤提前截断或四舍五入；合计和差异基于高精度结果计算，页面展示时再统一保留最多 6 位小数。
- 小数末尾的 0 不强制展示，例如 1、1.2、1.234567 均可按实际有效位展示；超过 6 位时按统一舍入规则处理。具体舍入方式待财务确认。

## 四、功能需求

### 4.1 查询区

#### 4.1.1 查询项

| 序号 | 查询项 | 控件 | 说明 |
|---|---|---|---|
| 1 | 发货单号 | 类型下拉 + 输入框 | 类型：中台发货单号 / ERP 发货单号，默认中台；支持输入多个 |
| 2 | SKU | 类型下拉 + 输入框 | 类型：SKU / 海外仓 SKU / FNSKU，默认 SKU；支持输入多个 |
| 3 | 发货计划 | 输入框 | 支持输入多个 |
| 4 | 目的仓 | 多选下拉 | 可搜索、可清空、折叠标签 |
| 5 | 物流渠道 | 多选下拉 | 同上 |
| 6 | 运输方式 | 多选下拉 | 同上 |
| 7 | 平台 | 多选下拉 | 同上 |
| 8 | 店铺 | 多选下拉 | 同上 |
| 9 | 团队 | 多选下拉 | 同上 |
| 10 | 创建人 | 多选下拉 | 同上 |
| 11 | 创建日期 | 日期范围 | 开始日期 ~ 结束日期 |
| 12 | 是否有差异 | 单选下拉 | 是 / 否，默认全部 |

#### 4.1.2 查询逻辑

- 不同查询项之间使用「并且」关系。
- 同一查询项输入多个值时使用「或者」关系。
- 单号类查询支持模糊匹配；SKU 类支持明细匹配，命中任意一个 SKU 明细即返回对应发货单。
- 点击「重置」恢复所有默认条件。

#### 4.1.3 布局与展开/收起

- 查询区默认最多展示两行，按组件宽度自然换行，不写死字段所在行。
- 查询项溢出到第三行或更多时，显示「展开」按钮；展开后显示全部查询项，点击「收起」恢复前两行。
- 按钮组（展开/收起 → 查询 → 重置）固定在第二行最右侧，不随查询项数量变化移动。

### 4.2 列表展示

#### 4.2.1 列定义

| 序号 | 列名 | 固定 | 说明 |
|---|---|---|---|
| 1 | 目的仓 | 固定左 | 单值 |
| 2 | 发货单号 | 固定左 | 中台发货单号 + ERP 发货单号，ERP 单号带「易仓」来源标签，无值显示「—」 |
| 3 | 平台 / 店铺 / 团队 | 固定左 | 三字段分行展示 |
| 4 | SKU | 固定左 | 单值 |
| 5 | 发货计划 | 否 | 单值 |
| 6 | 履约数量 | 否 | 实际发货 / 收货 分行展示，右对齐 |
| 7 | 发货单总费用 | 否 | 右对齐；表头增加问号图标，悬停显示「发货单总费用 = 头程物流费 + 清关税费 + 其他物流费用」 |
| 8 | SKU单位头程成本（CNY） | 否 | 右对齐，实际发货为 0 显示「—」 |
| 9 | 差异 | 否 | 右对齐，0 灰 / 非 0 红 |
| 10 | 物流信息 | 否 | 运输方式 / 物流渠道 分行展示 |
| 11 | 创建时间 | 否 | 单值，无值显示「—」 |

#### 4.2.2 列表行为

- 数据超过一页时底部显示分页器。
- 表头上方显示「共 X 条」查询结果总数（按查询结果统计，不分页）。

### 4.3 整行合计

- 表格最底部展示一整行合计，各单元格与对应列严格对齐。
- 仅以下三列位置显示数值，其余列留空：
  - 发货单总费用列：合计（按单去重）。
  - SKU单位头程成本（CNY）列：「合计（CNY）」+ 合计金额。
  - 差异列：「合计（CNY）」+ 合计差异（0 灰 / 非 0 红）。
- 合计基于查询筛选后的全部结果计算，翻页不影响。

### 4.4 导出

- 点击「导出」将**全部查询结果**导出为 CSV 文件（文件名：头程费用明细.csv）。
- 导出内容包含全部展示字段。

### 4.5 其他交互

- 「刷新」：重新拉取最新分摊结果。
- 页码切换、查询、重置后，列表与合计联动刷新。

### 4.6 自动触发分摊

- 当发货单已产生实际发货数量，且头程费用录入完成并保存时，系统自动触发分摊；头程费用包括头程物流费、清关税费、其他物流费用。
- 若先产生实际发货数量、后录入费用，则保存费用时触发分摊；若先录入费用、后产生实际发货数量，则保存实际发货数量时触发分摊。
- 实际发货数量、物流方式、体积参数或费用金额发生变更并保存时，系统重新计算该发货单，使用最新数据覆盖原分摊结果，不重复累加。
- 分摊完成后，结果写入分摊结果数据，并在「头程费用」页面查询展示；已打开页面需刷新或重新查询后获取最新结果。
- 发货单缺少实际发货数量、整票总计费重为 0 或费用尚未录入完整时，不生成有效分摊结果，并保留未分摊状态或明确的异常提示。

### 4.7 分摊结果精度展示

- 页面及导出中的金额、单价、差异、分摊单价等字段最多保留 6 位小数。
- 分摊单价使用高精度计算结果参与 SKU 分摊，不使用页面展示后的 6 位小数反算，避免累计误差导致差异扩大。
- 查询页的单位头程成本、发货单总费用、差异，以及分摊结果中的分摊单价，均按第 3.4 节规则展示。
