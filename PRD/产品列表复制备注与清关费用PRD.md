| 项目 | 内容 |
|---|---|

## 一、背景与目标

同一产品发往不同国家/地区的仓库时，包装规格可能不同。例如欧洲市场可能有特殊的包材设计要求（必须使用欧洲版包装），但产品本体相同。

为满足该场景，需要在产品列表中基于已有产品快速「复制」出新的 SKU 档案，分别维护不同包装/发货规格。

**解决方案**：不在系统中建立复杂的关联逻辑，而是在商品基本信息中增加一个「备注」字段。

**用途限制**：该备注仅供运营人员查看，用于识别是 FBA 发货规格、海外仓规格还是欧洲特定规格；后续新建发货单时，程序不需要读取此字段。

同时，跨境发货需要按目的国维护清关费用信息（目的国 HS Code、清关单价、清关税率），用于运营测算与核对，不参与下游单据计算。

目标：

1. 支持基于已有产品快速复制出新产品档案，减少重复录入；
2. 通过备注区分同一产品的不同包装/发货规格；
3. 记录复制来源，便于后续追溯；
4. 按国家维护清关费用，便于运营测算不同目的地的清关成本。

**范围**：单条复制 + 备注字段（所有 SKU）+ 清关费用（物流报关清关分区）；不含批量复制、来源筛选与多级复制链。

## 三、产品复制

### 3.1 业务流程

1. 在产品列表某行点击「复制」；
2. 打开 SKU 信息弹窗（新建态），自动带出被复制产品的信息，SKU 默认为原编码；
3. 用户修改 SKU（及其他需要调整的字段）；
4. 点击「保存」，校验通过后新增一条产品记录并返回列表；
5. 新记录在 SKU 下方展示「复制自 原SKU」。

### 3.2 复制入口

- 位置：列表操作列「复制」，所有产品行均可使用（含组合品、停用产品）。
- 点击后不产生数据，只有保存成功才新增记录。

### 3.3 复制弹窗

复用现有「SKU信息」弹窗，以新建态打开：

- 标题：`SKU信息` + SKU 编码，默认显示被复制的 SKU，随 SKU 输入实时更新；
- 标题下方灰色副标题：`产品名称 · 复制自 原SKU`，超长省略，悬停可看全文；
- 字段：除 SKU 外，其余业务字段全部按原产品带出，均可编辑；
- SKU：默认等于原产品编码，**可编辑、必填**；
- 底部按钮：`关闭`、`保存`；
- 点击「关闭」或遮罩关闭：放弃本次复制，不产生数据。

### 3.4 字段复制规则

| 分类 | 字段 | 规则 |
|---|---|---|
| 基础信息 | SKU | 默认原编码，可编辑；保存时唯一性校验 |
| 基础信息 | 产品名称、品名（英文）、关联 SPU、型号、识别码、产品系列、品牌、产品类型、配货类型、新品/老品、销售状态、一级/二级类别、单位、产品负责人、备注 | 按原产品带出，可编辑 |
| 组合明细 | 组合品的子 SKU 及数量 | 按原产品带出，可编辑 |
| 尺寸重量 | 单品规格、包装规格、箱柜尺寸/体积/重量 | 按原产品带出，可编辑 |
| 报关物流 | HS code、申报价值、物流属性 | 按原产品带出，可编辑 |
| 清关费用 | 国家、清关 HS CODE、清关单价、币种、清关税率、备注 | 按原产品带出，可增删改 |
| 采购信息 | 供应商、供应商料号、采购周期、最小起订量、采购员 | 按原产品带出，可编辑 |
| 关联辅料 | 辅料、单位成本、辅料比例、备注 | 按原产品带出，可编辑 |
| 图片 | 产品主图、实物图 | 按原产品带出，可编辑 |
| 审计字段 | 创建人、创建时间、更新人、更新时间 | 创建人 = 当前登录账号；创建时间、更新时间 = 保存时间 |
| 溯源字段 | 复制来源 SKU、来源产品 ID、复制时间 | 系统自动记录，不可编辑、不可清空 |

补充：复制品默认「启用」，不继承原产品的停用状态。

### 3.5 保存校验

- SKU 必填；
- SKU 必须唯一：未修改编码直接保存时，提示 **「SKU 编码「XXX」已存在，请修改后保存」**，弹窗保持打开，用户修改后可再次保存；
- 其他必填项沿用现有新增校验（产品名称、产品类型、配货类型、品牌、类别、单位、产品负责人、申报价值等）；
- 校验失败时停留在弹窗，已填内容不丢失。

### 3.6 SKU 编码规则

- SKU 保存后不可修改：编辑、查看时 SKU 输入框置灰禁用；
- 仅新建、复制时可填写 SKU；
- 复制默认沿用原编码，需要用户主动修改，依靠保存时的重复校验提醒。

## 四、商品备注

### 4.1 使用说明

- 用途：标注同一产品的规格差异，供运营识别 FBA 发货规格、海外仓规格、欧洲特定规格等；
- 适用范围：所有 SKU 的新建、编辑、复制，不区分是否为复制品；
- 使用流程：打开 SKU 信息弹窗 → 在基本信息底部填写备注 → 保存 → 列表备注列与备注查询可识别；
- 用途限制：仅供运营人员查看与筛选，发货单等下游单据不读取该字段，不参与任何计算。

### 4.2 备注输入框（所有 SKU）

- 入口：SKU 信息弹窗 → 基本信息最下方；
- 控件：多行文本输入框，横向占满表单宽度，约 3 行高度；
- 必填：否；
- 内容：自由文本，建议填写规格标识，如「FBA 发货规格」「海外仓规格」「欧洲规格（欧洲版包装）」；
- 编辑已有 SKU 时若备注发生变化，写入操作日志。

## 五、物流报关清关

### 5.1 分区与导航

- 右侧导航项由「物流与报关」改为「物流报关清关」；
- 分区标题由「报关与物流信息」改为「物流报关清关」；
- 分区内保留原有 HS code、申报价值、申报中文名、申报英文名、物流属性，并在下方新增「清关费用」表格。

### 5.2 清关费用表格

列结构：序号、国家、清关 HS CODE、清关单价（含币种）、清关税率（%）、备注、操作。

- 国家：表格底部「＋ 添加国家」按钮新增一行，行内通过下拉选择单个国家；点击次数决定行数，一行只能有一个国家。
- 国家互斥：已选国家在其它行的下拉中置灰不可选，避免重复维护。
- 移除：每行提供「移除」，删除该行。
- 无国家时表格为空，仅保留表头与「＋ 添加国家」按钮。

### 5.3 字段说明

- 国家：按下方「国家枚举」维护，共 43 个。
- 清关单价：非负数字，展示两位小数；每行独立选择币种，默认 `CNY`。
- 币种枚举：按下方「币种枚举」维护，共 22 种。
- 清关税率：非负数字，范围 0–100，展示四位小数并以 `%` 结尾，非必填。
- 备注：自由文本，非必填。
- 用途：仅供运营测算与核对，不写入发货单等下游单据，不参与自动计算。

### 5.4 批量填充

- 清关 HS CODE、清关单价、清关税率三列表头提供「批量」文字按钮；
- 点击后在该列头下方弹出小面板：输入值（清关单价可同时选择币种），右下角「取消」「确认」；
- 确认后将该值批量应用到当前所有国家行，并提示应用行数；
- 无国家行时提示「请先添加国家」；
- 批量填充与新建采购计划使用同一套触发按钮、弹层尺寸、按钮样式与操作区布局，不另起样式。

### 5.5 保存、回填与只读

- 清关费用随产品档案保存，重新打开弹窗时回填；
- 复制产品时清关费用整体带出，可继续增删改；
- 保存校验：国家不能为空且不能重复；清关单价非负；清关税率 0–100；
- 只读查看时：「＋ 添加国家」「移除」「批量」及行内全部输入框、下拉均禁用置灰。

## 六、列表展示与查询

### 6.1 复制来源标识

- 复制品在 SKU 下方展示灰色小字 `复制自 原SKU`（12px，单行省略，悬停显示全文）；
- 点击该标识：打开来源产品的只读详情弹窗；
- 来源产品已被删除：显示 `复制自 原SKU（已删除）`，置灰不可点击；
- 非复制品不展示该标识；
- 复制品再次被复制时，来源记为**直接来源**（A→B→C，C 显示复制自 B）。

### 6.2 备注列

- 位置：产品负责人字段后新增「备注」列；
- 空值显示 `—`；
- 长文本单行省略，悬停显示全文。

### 6.3 备注查询

- 位置：查询区「产品负责人」后新增「备注」输入框；
- 支持模糊查询（包含匹配、不区分大小写），与其他查询条件组合生效；
- 点击「重置」时清空备注查询条件。

### 6.4 导出

- 产品资料导出模板需同步包含「备注」列，列位置与列表一致（产品负责人后）；
- 导出内容与列表展示一致，备注为空时导出为空单元格；
- 避免导出文件缺少备注列，导致运营无法区分 FBA / 海外仓 / 欧洲规格。

## 七、数据与日志

- 备注：所有产品记录均可保存备注内容，修改时写入操作日志；
- 清关费用：以 `清关国家 + 清关 HS CODE + 清关单价 + 币种 + 清关税率 + 备注` 存于产品档案，随保存更新；
- 复制溯源：新增产品记录时写入复制来源 SKU、来源产品 ID、复制时间；
- 操作日志：复制保存时新增一条「新增」记录，内容包含 `复制自 SKU：原SKU` 及产品创建信息；
- 来源产品删除后不清理复制关系，列表中按「已删除」展示。

## 八、异常与边界

| 场景 | 处理 |
|---|---|
| 未改 SKU 直接保存 | 提示编码已存在，阻止保存 |
| 修改后的 SKU 与其它产品重复 | 同上 |
| 复制组合品 | 子 SKU 明细一并带出；组合明细为空时按现有组合品校验 |
| 关闭弹窗 | 不产生任何数据 |
| 来源产品已删除 | 列表标识显示「已删除」，不可跳转 |
| 备注为空 | 允许保存，列表显示 —，不参与任何下游逻辑 |
| 新增国家行未选择国家 | 保存时提示「请选择国家，或移除未选择国家的行」 |
| 国家重复 | 行内下拉置灰不可选；保存时再次校验并提示 |
| 清关单价 / 税率越界 | 单价小于 0、税率不在 0–100 时提示并阻止保存 |
| 无国家行时点击批量 | 提示「请先添加国家」 |

## 九、验收标准

1. 任意产品点击「复制」，弹窗带出原产品信息，SKU 默认原编码且可编辑；
2. 弹窗副标题显示「产品名称 · 复制自 原SKU」；
3. 未改 SKU 保存报编码重复，弹窗不关闭；修改后保存成功，列表首行新增该产品；
4. 新行 SKU 下方显示「复制自 原SKU」，点击可打开来源产品只读详情；
5. 编辑已保存产品时 SKU 置灰不可修改；
6. 删除来源产品后，复制品的来源标识显示「（已删除）」且不可点击；
7. 复制品再次复制，来源记录为直接来源；
8. 任意 SKU（新建、编辑、复制）可在基本信息底部填写备注，非必填，保存后生效；
9. 列表产品负责人后展示备注列，空值显示「—」，长文本省略且悬停可见全文；
10. 查询区备注支持模糊查询，重置后清空；
11. 备注不出现在发货单等下游单据中，不参与任何计算；
12. 导出的产品资料包含备注列，内容与列表一致；
13. 右侧导航与分区标题均为「物流报关清关」，分区内展示清关费用表格；
14. 点击「＋ 添加国家」新增一行，行内下拉单选国家，已选国家在其它行不可重复选择，支持逐行移除；
15. 清关单价支持 22 种币种，默认 CNY；清关税率范围为 0–100；
16. 清关 HS CODE、清关单价、清关税率可通过列头「批量」一次应用到所有国家行；
17. 保存时对空国家、重复国家、单价为负、税率越界进行拦截；
18. 保存后重新打开弹窗清关费用回填正常，复制产品时清关费用整体带出；
19. 只读查看时「添加国家」「移除」「批量」及行内控件全部禁用。
